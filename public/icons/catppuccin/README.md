# Catppuccin 文件图标

此目录包含 [Catppuccin Icons for VSCode](https://github.com/catppuccin/vscode-icons) 的部分图标，来源版本为 `v1.26.0`，提交为 `b6915da9f6889b683a110aa747de96c2820a537d`。

- `latte/` 用于 Pi Imagin 的浅色主题。
- `mocha/` 用于深色主题。
- SVG 的透明通道作为遮罩，颜色使用 `var(--text-dim)`，因此两个主题都显示单色图标。
