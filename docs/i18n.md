# 界面国际化

Pi Imagin 使用内部国际化层，避免增加运行时依赖。界面语言与服务端、API 响应和 pi 本身的输出分开管理。

## 内置语言

| 标识 | 语言 |
| --- | --- |
| `en` | 英文 |
| `zh-CN` | 简体中文 |
| `zh-TW` | 繁体中文 |

界面默认使用简体中文，已保存的 `pi-locale` 优先；用户从常规设置中的三张语言卡片切换，无需刷新。语言名称使用各自语言的原名，不随当前语言翻译。语言解析工具仍保留浏览器语言映射，不能据此覆盖已保存选择或改变当前默认值。

## 在组件中使用

客户端组件通过 `useI18n()` 获取 `t()`，并放在 `I18nProvider` 下。应用根节点 `app/page.tsx` 已提供该环境。

```tsx
import { useI18n } from "@/hooks/useI18n";

export function ExampleButton() {
  const { t } = useI18n();
  return <button aria-label={t("example.open")}>{t("example.open")}</button>;
}
```

动态值通过参数传入，不要拼接翻译片段；句子结构由各语言包决定。

```tsx
<span>{t("session.messageCount", { count: messageCount })}</span>
```

```ts
"session.messageCount": "{count} 条消息"
```

## 增加语言

1. 在 `lib/i18n/messages/` 新建使用 BCP 47 标识的文件，例如 `ja.ts`。
2. 从 `en.ts` 复制完整消息键，保留键名和参数名称，仅翻译值。
3. 在 `lib/i18n/registry.ts` 导入语言包并加入 `localePlugins`。
4. 更新 `lib/i18n/types.ts` 的 `Locale` 联合类型及明确列出内置标识的校验。
5. 扩展 `registry.test.mjs` 和 `format.test.mjs`，验证语言注册、浏览器语言解析及插值行为。

```ts
import type { LocalePlugin } from "../types";

/** Pi Imagin 的日语语言包。 */
export const jaLocale: LocalePlugin = {
  id: "ja",
  label: "日本語",
  messages: {
    "common.language": "言語",
    // 在此补齐所有共享消息键。
  },
};
```

`label` 用于语言选择器，`getSupportedLocales()` 自动读取注册列表。缺失消息先回退到英文，再返回键名，并在开发环境发出警告；面向用户的语言包应尽量完整。

## 修改界面文案

- 在 `en.ts`、`zh-CN.ts` 和 `zh-TW.ts` 同时增加稳定消息键。
- 使用 `chat.*`、`files.*`、`settings.*`、`common.*` 等功能命名空间。
- 显示文字、`title`、`aria-label` 和 `placeholder` 都通过 `t()` 读取。
- 数量、名称、路径等运行时值使用插值。
- 产品、模型、Provider 名称、命令、路径、用户内容、工具输出和服务端错误详情保持原值。
- 不通过匹配英文错误字符串翻译 API 错误，仅翻译界面的本地兜底说明。

Agent、API Key、Provider、Token、worktree、Diff、CWD、Shell、Git、HEAD、OAuth、Mermaid 等技术名称可以保留英文及惯用大小写，其周围操作和状态使用当前界面语言；模型、插件、技能、提示词、上下文、缓存等通用概念使用对应译名。

工作区主导航、会话侧栏、搜索弹窗、项目管理、辅助标签、分支提示、状态栏与终端控件都使用同一语言上下文，包含隐藏状态下的 tooltip 和可访问名称。日期分组及默认归档分组只翻译显示，模型键、折叠偏好和用户项目名称保持原值。

加载占位、文件操作、文件编辑与关闭确认也使用语言包。本机文件名和外部错误详情作为插值或原始详情展示，不能通过翻译修改文件内容、路径或草稿。`node e2e/workspace-i18n.mjs` 使用私有临时数据验证三语言实时切换、搜索重试、项目弹窗、辅助区及终端；桌面与浏览器共用验收流程。

完整历史查看器在无同源权限的 iframe 中展示。只本地化查看器的搜索、筛选、概览和操作，不替换 SDK 事件或会话正文。父页面在加载和语言切换时发送固定的语言标识；沙盒只接受 parent 来源及三种内置标识，使用 textContent／属性更新控件，不重载文档，保留阅读位置和筛选。

## 验证和原则

```bash
node node_modules/typescript/bin/tsc --noEmit
npm run lint
npm test
```

开发期间不要运行 `next build`，原因见 [开发约定](../AGENTS.md)。语言支持应帮助用户理解和操作界面，不能作为技术门槛。新增语言或改进少量文案时，不必改写 API 协议、pi 输出或引入大型翻译框架。
