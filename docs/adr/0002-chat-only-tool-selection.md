# 0002：将仅聊天保存为会话资源策略

## 决策

明确的空工具选择表示“仅聊天”，不能仅当作当前工具数组偶然为空。

普通仅聊天会话不加载扩展、技能、提示词模板、主题或 pi 基础提示词。精确系统提示词是默认资源加载器依顺序发现的上下文文件正文，包括全局和项目的 `AGENTS.md`、`AGENTS.override.md`、`CLAUDE.md`；不额外添加工作目录或前后缀。

子智能体若工具为空且两个资源开关关闭，则只使用配置中的系统提示词，不加载上下文文件或 pi 基础提示词。继承的父上下文放在委派任务中，不附加到系统提示词。预加载输入文件也属于任务准备，不因此增加工具。

## 持久化

普通会话保存版本化自定义记录：

```json
{
  "type": "custom",
  "customType": "pi-web:tool-selection",
  "data": { "version": 1, "tools": [] }
}
```

最新有效条目生效。无条目或 `cleared: true` 表示采用 `defaultTools`；空 `tools` 表示仅聊天；非空恢复用户选中的内置工具。保存的是加入扩展工具之前的选择。

子智能体使用自己的 `resourceSnapshot` 保存工具、技能和扩展开关，不重复写该条目。保留版本和旧标识，保证已有会话仍可恢复。

## 应用时机

资源策略在创建服务前解析，避免仅聊天导入或执行扩展。精确提示词通过 `before_agent_start` 返回 `{ systemPrompt }`，不得修改 SDK 内部只读状态。

非空预设可更新已有包装器；跨越仅聊天边界需要保存选择并重建。持久化会话保留 ID 和 JSONL；尚未保存的空会话可重新创建。当前实现详见 [工具约定](../agents/tools.md)。
