# 0003：内置子智能体开关与扩展优先级

## 决策

内置子智能体是隐藏的内联扩展，默认关闭，由 `~/.pi/agent/agents/settings.json` 的 `builtInEnabled` 控制。

普通非仅聊天资源加载器始终保留工厂，重载可切换开关；关闭时工厂不注册工具。运行时守卫也拒绝关闭后残留的 `Agent` 调用。

启用内置实现后，仅抑制可明确识别为旧 `pi-subagents`、且注册 `Agent`、`get_subagent_result` 或 `steer_subagent` 的扩展。无关扩展不因同名被移除，名称冲突由 SDK 正常报告。

关闭内置实现后不再抑制旧包，用户仍可在插件设置管理它。历史子会话继续可读，已运行的任务不会因开关改变而中止。
