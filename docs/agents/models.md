# 模型、服务商与认证

## 默认模型和推理级别

`GET /api/models` 从全局设置读取默认模型，新会话据此预选。浏览器的模型或推理级别选择作用于当前会话，不能自动写回全局设置。

模型行和推理菜单中的星标通过 `/api/models/default` 显式保存默认值。目标模型必须在已启用范围中；项目 `.pi/settings.json` 覆盖对应键时，返回 `409`、`reason: "project-scope"` 和 `settingsPath`。

运行中可调整推理级别：已开始的请求保留原级别，下一次请求重新读取。升级 SDK 时验证这一点，若不再有效则禁用运行中的控件，不能让界面显示变化而请求不变。

## 目录刷新

内置目录固定在 SDK 版本，较新目录来自 pi.dev 的叠加数据，保存在 `models-store.json`，可离线恢复。普通列表请求和会话创建只读取已有数据，不能顺带联网刷新。

仅用户点击“刷新目录”时，`/api/models/refresh` 调用 `refresh()`。遵守 `PI_OFFLINE`，合并并发刷新；刷新后使模型缓存失效，面板重新加载本地运行时。

## 延迟注册的扩展模型

有些扩展在 `session_start` 才重新注册模型。`lib/deferred-provider-models.ts` 记住已见过的可用模型，仅为当前完全未注册的服务商补回；已注册但认证不可用的服务商不能补回。需要延迟模型的会话先建立，再在扩展启动后选择目标模型。

仅聊天不加载扩展，因此不得通过这份记忆绕过资源策略。项目专用模型也不能假定在另一个工作目录可用。

## 已启用模型范围

`enabledModels` 使用 SDK 的 `--models` 语义：服务商/模型通配符、非通配符模糊匹配及可选 `:thinkingLevel`。通过 `resolveModelScopeWithDiagnostics()` 解析；全部不匹配时 SDK 会退回所有模型，所以不能用空范围表示“禁用全部”。

模型顺序保持范围列表顺序；没有范围时只按服务商排序，同一自定义服务商保持文件顺序。

开关仅经 `/api/models/enabled` 修改，浏览器不拼接通配符。规则如下：

- 保留未匹配条目、原顺序和推理级别后缀。
- 关闭模型只展开覆盖它的模式；开启模型追加明确引用。
- 验证 `provider/*` 和 `provider/**` 的实际匹配集合；`*` 不跨 `/`，不能假设能覆盖嵌套模型 ID。
- 完全开启的多模型服务商可折叠为经验证的通配符；单独明确引用和带推理后缀的条目保留。
- 拒绝关闭最后一个模型，返回 `409` 和 `reason: "last-model"`。
- 项目设置覆盖全局范围时，开关只读，显示实际设置路径。
- 仅 `prune` 清理不匹配条目，`clear` 删除范围键；普通开关不能顺带修复其他条目。
- 保存模型配置后执行 `resync`：先迁移模型引用，再迁移服务商名称，重新验证范围并保留原先完全启用的服务商。编辑器需同步跟踪数组移动，避免把新增、删除误判为改名。

内置及扩展服务商提供逐模型开关；`models.json` 自定义服务商提供整体开关。部分启用时整体开关显示关闭，点击完成全部启用。禁用原因必须是可见说明，不能只放在悬浮提示中。

## 认证和模型配置

模型编辑器保存 `~/.pi/agent/models.json`。未显式设置的内置服务商 `api` 保持省略，不能在打开面板时保存猜测的协议；新自定义服务商默认 `openai-completions`。

服务商分组根据认证能力和已存凭据类型决定，不能硬编码 ID。一个服务商只有一份凭据，按类型删除时需在认证文件锁下检查，避免误删另一种登录。

API Key 使用 `lib/provider-credential-store.ts` 保存；不要通过可能触发无界目录刷新的 `ModelRuntime.login()` 写入。状态接口不能返回原始 Key。OAuth 和设备码登录使用已有登录路由，人工验证码通过短期回调传递。

`set_model` 每次先执行 `refresh({ allowNetwork: false })`，再解析目标模型。重新选择同一模型也会应用新兼容配置，无需重启服务。

模型测试路由为 `app/api/models-config/test/route.ts`，测试包含系统提示词，以检测接口对 `developer` 角色的支持。不支持该角色时，设置 `compat.supportsDeveloperRole: false`，保持系统提示词为 `system`，不需要关闭推理能力。

模型发现只复制含义明确的能力字段，如 `contextWindow`、`maxTokens`、`reasoning: true` 和对应 pi 级别的映射；忽略含义不稳定的字段及无效值。
