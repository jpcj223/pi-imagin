# MCP 服务器添加与导入

## 添加请求

浏览器发送原始粘贴文本，服务器重新用同一个导入器解析；不能直接信任浏览器构造的配置。`POST /api/mcp` 的 `action: "add"` 接受文本、作用域、补充值、秘密引用、选中服务器、名称、pi 语法开关、目录信任及宿主变量确认。

验证顺序为请求来源、JSON、工作目录、MCP 开关、请求形状、目标文件、文本解析、名称、字段补齐、SDK 配置校验和写入。文本最多 256 KiB。重名给出可用建议，真正插入时在文件锁下再次检查。

补充的普通值按字面量转义；显式环境引用仅放入 SDK 会解析的字段。项目配置不保存字面密钥，改用用户指定的环境变量引用。

## 宿主环境变量

粘贴内容若会向 HTTP 请求头或 OAuth 密钥发送服务端已有环境变量，需要确认变量名称；仅返回名称，不返回值。stdio 的自身环境、用户手工输入的变量和明确启用的 pi 语法按既有规则处理。确认只覆盖已列出的名称，文本改变后重新判断。

任何作用域都不能引用 `PI_WEB_PASSWORD`。该限制同时防止模型、项目配置和外部导入把网页登录密码传到第三方。

## 项目保存与信任

项目写入需要有效的目录信任。没有信任资源、没有本目录或祖先决定的新目录，可在用户请求的同一步中信任并写入；否则返回项目不可信。

判断信任范围不能越过更具体的拒绝，过宽目录不给出快捷信任。一个目录的信任及写入操作串行；写入失败撤销本次新加的信任决定，不能留下与实际保存结果不符的权限。

## 导入格式

支持普通 URL、命令行、`pi/claude/codex/gemini mcp add`、多种客户端的 JSON/JSONC，以及 Cursor 和 VS Code 安装链接。导入器只解析，不执行命令、不访问链接、不读取本机秘密。

命令解析不接受管道、重定向、命令替换和无法确定的 Shell 语法；保留参数顺序，正确区分环境赋值与可执行文件。引用和反斜杠处理必须与格式语义一致。

JSON 导入保留每个可用条目，并分别报告无效项；不要因一个错误静默丢弃其他条目。缺失值成为补充输入，秘密使用密码输入框。仅解析格式中明确支持的变量语法，字面 `$`、反斜杠和 `!` 不能意外变成 SDK 的环境或命令展开。

原始 pi JSON 的支持需要明确开启，避免别的客户端配置被误判为可执行的 pi 语法。导入预览显示目标作用域、名称、命令、URL、变量和注意事项，保存结果仍以服务端重新解析为准。


## 添加页面

默认只要求粘贴服务商提供的地址、命令或配置；名称自动生成且可修改，摘要直接显示传输与真实连接目标，缺少的参数和密钥按原解析器补填。示例和详细解析默认折叠，示例使用无边框、宽行距的可点击列表，点击整行填入草稿后自动收起并聚焦输入框，不自动保存或测试；填写后仍可重新展开。示例随正文滚动，不设置内部滚动条；演示地址 mcp.example.com、placeholder.invalid 经界面及保存端共同拒绝，必须替换真实端点。目录链接收在“查找 MCP”中。

应用内范围控件统一放在页面工具栏；添加页显示缩略配置路径和复制按钮，仅在选择项目后显示该项目的限制与信任入口，密钥及宿主环境变量的必要确认仍直接展示。底部“取消”清空粘贴内容、名称、字段、密钥、预览和错误，重新打开为空白；选择的全局／项目范围及已保存服务器不受影响。“添加并测试”先保存、再沿用一次连接测试；测试失败不删除已保存配置。多条目粘贴继续选择单个服务器添加，批量导入不属于本次变更。

网站入口管理弹窗支持增删改、恢复默认网站及浏览器本地持久化，校验 HTTP/HTTPS 地址并拒绝含登录凭据的链接。该偏好与 MCP 服务器配置完全独立；恢复网站不修改任何服务器。名称、链接、取消与保存沿用应用国际化和弹窗焦点约定。

添加操作通过门户放入 MCP 共用底栏，与刷新及计数同一条操作区，长正文独立滚动；示例标签与代码有层级，整行键盘激活保持只填入。演示地址禁止提交的校验保留，但不再显示底部重复的演示地址说明。

URL 类填写示例使用 Microsoft Learn 官方文档 MCP：`https://learn.microsoft.com/api/mcp`，点击仅填入，仍由用户明确添加和连接。旧占位地址校验保留。
