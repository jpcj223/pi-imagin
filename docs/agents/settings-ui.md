# 设置界面与共享组件

设置从最左导航栏底部打开，重复点击设置或按 Escape 返回进入设置前的页面：从插件或技能进入则返回原资源页，从工作区进入则返回原工作区。在设置分区间切换不覆盖最初入口；主动点击主页、全局搜索、插件或技能导航使用对应目标，并清除临时返回记录。工作区使用 `open` 隐藏并停用页面，保留已访问分区及未保存输入。隐藏时不监听 Escape、不占用焦点；重新打开恢复分区与输入，聊天草稿和文件视图独立保留。

嵌入式设置与插件占用相同的工作区范围，只保留最左侧全局导航；设置打开时会话／项目侧栏及中央工作区停用，不能通过键盘聚焦到覆盖层后方。主页和全局搜索先关闭设置，再完成原操作。设置组件保持挂载，不能因导航清空未保存的模型配置。浏览器和桌面使用相同处理。

## 字体和布局

`FontSettings.tsx` 分别设置界面/聊天字体及等宽字体。字体行使用统一网格：名称输入框、字重和重置位置对齐；字重范围 100–600。聊天字号和内容宽度独立设置。

字体仅指浏览器所在设备已安装的字体，不枚举、不上传、不下载。名称作为数据处理：拆分逗号、规范引号、补充默认字体族，不能直接插入样式表或可执行 CSS。

每个字体的重置只清除其名称和字重，不影响另一字体、聊天宽度或字号。标题、Markdown 强调和代码高亮保留原本字重，不使用全局 `!important` 覆盖。

应用根组件持续挂载字体偏好，实时应用并通过存储事件同步其他标签。已有草稿重新测量尺寸；终端重新适配字体，不重启进程或事件流。

## 设置页面与文件浏览器位置

设置在主窗口中占满全局导航右侧的内容区域，不随会话侧栏展开、收起或宽度改变而移动，不使用遮罩弹窗。顶部采用与插件一致的 36px 标题行，移除“返回工作区”和页面关闭按钮；窄屏保留主页出口。左侧分类常驻、右侧内容独立滚动；各配置区继续保持挂载，恢复对话或切换插件时保留草稿、选择与滚动。

设置分类栏、插件已安装栏与主页侧栏共用 `SIDEBAR_DEFAULT_WIDTH`（220px）及工作区实际侧栏宽度，沿用已有拖动偏好，不重置存储；两页边界使用同一 `useResizablePanel` 的分隔线事件，实时镜像宽度，释放后写入既有偏好。支持方向键、双击／Enter 恢复默认，沿用宽度限制；窄屏隐藏拖动柄，分类横向滚动，插件侧栏全宽。

常规设置正文最大 900px，随右侧空间收缩，在右侧内容区居中；主题、说明和分隔线使用同一正文边界。字体名称输入框适度加宽至最多 360px，字重和独立重置同行；滑杆行仍保持最大 600px，数值与重置对齐，开关留在同一控件列起点，不随正文一起拉长。分组间距收拢，窄内容区自动分行。语言在独立分组中以三张等宽卡片横排，保留语言名称、代码和当前选中状态；窄屏保持一行并收拢内边距。后台推送以原生 details 保留完整说明、注册与状态反馈，默认折叠，不自动申请通知权限；Shell 说明放在对应设置行之后。模型、子代理和 MCP 使用更宽的配置区域，保留原有对象列表和功能。新增排版只限定工作区设置页，主题和字体继续使用共享变量。

项目菜单进入左侧文件树；文件内容在右侧辅助面板打开，与会话目录共用面板。文件树切换时保持挂载，保留展开、搜索和上传状态。旧版文件位置偏好键保留兼容，但这一版布局不提供堆叠位置切换。

## 常规设置恢复默认

常规页底部提供恢复入口，先显示恢复范围并二次确认，取消不更改设置。恢复主题、两种字体及字重、聊天字号／宽度、思考默认展开、选中文字提问、发送按键、应用语言和命令执行环境优先级；恢复只清除排序覆盖，保留已添加和自定义环境；默认值沿用应用初始值，语言复用 `DEFAULT_LOCALE`。不清空存储，也不更改模型、插件、MCP、会话、侧栏宽度、通知权限或其他设置分区草稿。

确认时先通过 `/api/shell-profiles` 提交 `{action:"reset"}`，同一文件锁内恢复环境默认顺序并保留已添加项，保留 Code mode 等其他工具设置；共享写入失败则保留本机偏好供重试。写入成功后，通过既有偏好更新器恢复本机设置，无需刷新页面；恢复期间禁用常规选项，避免并发覆盖。活动会话在显式恢复默认后重载，重载失败与设置写入失败分开报告。浏览器存储不可用不应打断思考偏好更新或页面广播。

## 插件和技能

插件从最左主导航打开，覆盖会话侧栏与中央内容，主体为左侧列表及右侧卡片／详情两栏；设置分类不再重复列出插件，顶部不展示返回工作区或目录。沿用同一个配置页面实例，导航切换保持设置草稿及插件搜索，隐藏的会话侧栏不可获得焦点。旧插件分区值仍可解析，但不覆盖设置上次访问的分区。

插件侧栏固定展示已安装条目及筛选，右侧默认是独立的插件目录，不再提供已安装／搜索安装切换组。左侧为空只显示侧栏空状态，右侧仍可浏览、搜索和安装。顶部标题行与底部统计行均压缩到约 36px，不显示页面关闭按钮；窄屏保留主页导航入口，避免隐藏主导航后无法离开。

侧栏标题及数量按文字基线对齐；筛选框高 34px、文字 12px，边框沿用主题变量，焦点仍使用系统强调色。空状态与标题、搜索框外边缘左对齐，缩短搜索后的留白，主要提示与辅助说明保持清晰层级；此微调不改变侧栏宽度、右侧目录布局或搜索行为。

目录搜索由服务端只读适配 Pi 官方目录，键入搜索保留 350 毫秒防抖，首次首页不额外等待；固定上游、限制响应大小、取消过时请求、按实际分页链接判断下一批，缓存一分钟；空结果中的全站总数不当成命中数。文字目录独立返回，图标通过有界批量接口随后补齐，慢图标不阻塞卡片。上游格式变化和离线明确报错，不返回假的空列表。安装直接使用目录给出的 npm 来源，经原安装接口处理，全局／项目目标与信任规则保留。不再提供手动来源表单及添加插件入口。

目录采用滚动追加，不显示上一页／下一页；距离底部约 1200px 开始追加，每次只预取下一批，不能自动抓取全站。追加按包名去重，失败保留现有卡片并在底部重试，过时查询不得混入新结果。工作区启动就绪后在空闲时仅预热公共首页（节流模式跳过），不加载项目插件或执行插件。客户端公共目录内存缓存最多 40 页，详情最多 20 项；当前标签页保存一份首页快照（最长一天），过期快照先展示再刷新，损坏缓存忽略。缓存及预取共用请求，最后一个使用者离开才取消，不干扰仍在使用同一请求的页面。

点击卡片主体或名称在右侧打开独立详情，安装按钮不触发详情。短暂停留或聚焦卡片名称时可预热一个详情请求，点击后立即展示已有名称和描述，详细说明继续补齐。详情使用官方页面的 README／版本信息与 npm 的完整描述、仓库和运行要求，来源缺失则提示，不生成不存在的功能说明。外部 HTML 必须经过净化，链接仅限公开网页，不能沿用聊天 Markdown 的本地文件或应用深链能力。过长 README 显示长度限制和来源入口。详情返回目录恢复查询、累计列表及滚动；隐藏页面不清空已加载内容，避免滚动因内容收缩而丢失。

插件描述及来源 README 按上游原文展示，不再提供描述翻译、预置译文、原文／译文切换或翻译状态提示；不发起翻译请求、不下载语言资源、不启动翻译子进程。应用自身的菜单和操作文案仍按当前应用语言显示。

主导航的主页、搜索、插件和技能可拖动排序，设置固定在底部；移动超过阈值才开始拖动，释放到组外或按 Escape 取消，不触发导航。顺序存于浏览器并同步其他窗口，Alt+↑/↓ 可键盘调整，支持恢复默认。新技能入口追加到旧顺序末尾，保留既有排序。

无项目时只管理全局插件，不借用服务工作目录加载项目资源；指定目录仍校验原有允许根与项目信任。窄屏在列表与详情间前进、返回，列表和详情分别保留滚动状态。新增样式限定在插件页面，使用共享主题与配置控件；安装、启停、更新和卸载继续经原接口与 SDK。

插件操作经 SDK 的设置与包管理器执行。禁用插件写入空的资源数组；批量操作按项报告失败，检查 SDK 设置写入错误，不能把失败当成功。

技能从主导航打开独立页面，设置分类中移除技能入口；与插件共用 resource-workspace-page 的工作区边界、36px 标题栏及已有侧栏宽度／拖动偏好。页面占满全局导航右侧，去除设置分类和外围留白。旧 skills 分区标识保持兼容，但不再覆盖设置最后访问的分类。切换设置后关闭返回原资源页，主页、搜索与资源入口主动导航清除临时返回目标，组件持续挂载保留其他分区草稿。

技能目录采用左侧已安装列表、右侧目录／详情的两栏布局。目录与插件页复用 resource-catalog-heading 和 plugins-search-input：标题／简介在左、38px 搜索框在右，760px 以下自然换行；键入自动搜索和 Enter 立即搜索沿用原逻辑。安装范围、缩略目标路径与数量集中在下一行。查看目录技能详情时收起目录搜索，固定显示返回和安装操作。已安装详情独立显示返回工具栏，正文最大 960px、两栏分别滚动；卡片自适应列数。底部紧凑展示已安装数量与更新操作。样式独立限定 skills-config，与插件共用主题变量和配置控件。窄屏通过已安装列表入口在两栏间切换，默认展示目录，保留主页出口。

无项目时技能页面可浏览目录、安装及管理全局技能，项目范围不可用。服务端使用明确的全局设置上下文，不采用服务进程的当前项目；内容读取仍限定 SDK 已发现的精确文件路径，指定项目继续校验允许根及信任。

技能页每次进入默认展示技能目录，不自动选中或恢复上次技能；点击已安装技能打开详情，点击另一技能切换详情，再点当前项回到目录。插件已安装列表采用相同开关逻辑；两页均不再提供侧栏底部常驻返回，仅详情顶部保留“返回”；重复点击当前已安装项仍返回目录。技能和插件侧栏统一为全局、外置、项目三组：全局放应用安装的全局资源，外置放全局外置资源，项目保留当前项目的资源并用行内标记区分应用安装／外置。默认顺序全局 → 外置 → 项目，仅全局展开；标题整行可拖动，Alt+↑/↓ 也可排序，按页面保存展示顺序和折叠偏好。搜索临时展开命中分组，不覆盖折叠偏好；折叠仍保留数量与分组开关，排序不改变资源归属。独立扩展保持只读移除提示。来源不按名称或磁盘目录猜测：插件由各范围的 plugin-installs.json 记录确切安装入口，旧版没有记录的插件暂归外置；技能使用应用专属锁和 piImaginInstalled 标记，保留旧 CLI 元信息用于更新，但不会据此冒充应用安装。目录保持挂载，返回保留查询、安装范围、累计卡片与滚动；左侧支持本地筛选，分组开关仍作用于完整分组。窄屏在已安装列表与内容间切换，目录与详情保留独立滚动位置。

技能目录通过只读 `/api/skills/catalog` 适配 skills.sh 公共接口，首页在启动就绪后的空闲时间预热；不调用 CLI、不执行技能。目录按上游真实 200 项分页及 hasMore 追加，接近底部只预取下一页；搜索防抖 350ms、Enter 立即提交，搜索接口最多返回 200 项且不支持分页，达到限制提示细化关键词，不假造下一页。安装继续使用原接口及全局／项目信任边界。请求带时限与响应大小限制，取消过时查询，失败保留已加载卡片并可重试。客户端首页快照、40 页目录、20 项详情及请求复用遵循插件目录规则。

目录卡片只显示真实名称、仓库和安装数；点击主体展示公开页 SKILL.md，停留或聚焦 180ms 预热单个详情。已安装卡片按来源标识匹配本地文件，不按名字猜测；全局范围只认全局安装，项目范围优先当前项目并继承全局安装，不继承其他项目。技能卡片和详情入口共用同一查找规则，插件卡片和详情也遵守同一范围判断。未安装项遇到上游折叠预览时，通过固定 GitHub API 查询真实 SKILL.md 树路径，并按提交 SHA 读取完整文档；根目录文档须确认 frontmatter 身份，歧义路径拒绝随机选择。API 返回树截断、超限、限流或缺失时保留预览、明确提示并提供强制重试；仅在查看／预热单个详情时访问，不克隆仓库。服务端文件树缓存最多 20 个仓库、5 分钟，正文最多 1 MiB；来源文档以净化后的 Markdown 展示，相对链接落在真实公开文件地址。独立网站来源没有可验证的仓库安装目标时只展示来源入口，不猜测安装命令。外部说明共用净化组件，只允许公开网页链接，不赋予聊天的本地文件或深链能力。已安装详情仍从精确已发现路径读取，缓存最多 20 项、30 秒，更新成功清除对应缓存；预热仅在停留或聚焦条目时发生。

技能内容只读取 SDK 已发现的精确 Markdown 路径，大小限制 1 MiB。禁用模型调用仅编辑 frontmatter，保留格式；安装和搜索使用对应接口，项目安装在所选工作目录中执行。

分组开关放在侧栏标题中，显示数量。仅当所有可切换条目都开启时显示开启，部分状态不能伪装为全部开启。被策略阻止的条目需要可见解释。

## 共用界面规范

新增设置区和添加面板使用 `SettingsUi.tsx` 的共享组件，如作用域、保存目标、细节网格、底部状态和信任提示，避免复制实现。组件接受文字参数，由调用方传入翻译结果。

添加面板在一个位置明确“全局 / 项目”保存目标和路径。禁用原因、信任要求和缺失权限作为可见文字显示，并通过 `aria-describedby` 关联；不能只依赖手机无法触发的 `title`。

加载、错误、部分成功和重试状态应保留当前草稿，不强制重新打开设置。堆叠设置和对话框的 Esc、焦点恢复使用共享机制。

## 命令执行环境

Windows 常规设置增加“在外部终端使用 Pi”，默认开启。桌面启动按全局 `piImaginExternalPi` 设置注册或撤销当前用户 PATH 中 `%LOCALAPPDATA%/Pi Imagin/command-bin`，不修改系统 PATH，不覆盖用户另装的命令。入口指向当前安装附带的 Node 和 SDK manifest 中的 Pi CLI，桌面更新后刷新路径；关闭仅移除应用入口及其 PATH 项。已有系统终端需重新启动，其环境不会被追溯修改。应用内终端使用独立 terminal-bin，因此外部开关关闭后仍可运行 Pi；外部 CLI 沿用自身环境和 Pi 配置，不复制应用凭据。其他平台不提供此 Windows 注册开关。重置终端排序不改变该开关。

开关点击后先反馈目标状态，保存期间禁止重复操作；失败恢复上次状态并显示错误，不把未完成的保存当成成功。接口仍等待入口文件、用户 PATH 和全局设置完成保存，但将可能阻塞的系统环境广播移到后台，短时间变化合并广播；广播失败记录诊断，不撤回已经成功保存的注册表值。PATH 状态读取合并并发请求并缓存最多 3 秒，每次变更立即失效并刷新缓存，旧查询不能覆盖新写入结果。验证使用独立入口目录、模拟注册表和真实浏览器接口拦截，不反复切换用户真实 PATH。

常规设置以可排序列表替代 PowerShell/Bash 开关。Windows 首次使用内置 Windows PowerShell，再列出 CMD；其他系统使用账户默认 Shell 和系统 sh，相同路径不重复显示。系统内置项始终保留、不可移除，可调整优先级；实际检测到的额外环境和手动指定程序经固定指令启动验证后才能添加。移除只改变列表，不卸载程序或关闭已经启动的终端。列表、添加弹窗和错误提示沿用共享控件与主题变量，正文边界与其他分组一致，支持拖动、菜单及 Alt+方向键排序，窄屏收拢次要信息。

环境配置保存在全局 `settings.json` 的版本化 `piImaginShells`，通过原文件锁协调更新；客户端只能提交列表操作或添加资料，不能提交任意启动参数。恢复排序时检查完整项目集合，避免过期列表遗漏内置项。添加面板提供检测列表、显示名、命令语法和完整程序路径；桌面可用原生文件选择器，网页输入服务端电脑上的绝对路径。添加前验证失败保留表单，WSL 当前明确标记仅用于手动终端。

AI 使用排序后首个可用且已适配的环境，新建或重载会话时确定；运行中程序失效不跨语法执行已生成的命令。底部终端共用环境列表及顺序，保留浏览器已记住的手动选择。终端下拉只展示已配置的可用环境，不提供添加或排序入口；添加、移除、检测和排序统一在常规设置管理。移除列表项不影响运行进程；列表变更在当前页面及重新聚焦的窗口刷新。直接输入的 ! / !! 仍沿用 SDK Bash 通道。

验证入口：`lib/shell-profiles.test.mjs`、`lib/terminal-manager.test.mjs` 与 `e2e/shell-environments.mjs`。真实 Shell 测试使用临时目录和独立配置，浏览器/桌面检查使用独立服务，不修改用户配置。

## 资源安装与删除

插件、技能支持同页同时安装 A/B/C，按范围和来源独立记录进行中、错误和重试，同一目标防止重复提交；一次失败不禁用其他安装按钮。列表刷新使用请求序号忽略过时响应，安装时保留已显示的列表。技能卡片的已安装状态由真实发现列表推导，不能仅凭 CLI 输出或乐观状态标记。

技能 CLI 在每个任务的临时工作目录中安装，仅选择 Pi 和复制模式，兼容 .agents/skills 与旧 .pi/skills。发布到当前应用 agentDir/skills 或所选项目 .pi/skills，持锁合并安装记录，全局应用记录位于 agentDir/skills-lock.json，项目继续使用项目根 skills-lock.json；保留旧 CLI 全局记录的读取。当前应用和会话资源加载兼容旧 ~/.pi/agent/skills，避免桌面自定义 agentDir 漏掉此前安装的技能。安装失败清理本任务临时文件，不覆盖已有同名技能；更新先准备新副本、保留旧文件用于失败恢复。

npm 插件各自独立准备依赖缓存，准备阶段禁用生命周期脚本。SDK 仍负责最终安装、来源规范化和包设置持久化；共享 npm 前缀的依赖落盘及配置提交串行协调，避免并发 npm reify 覆盖其他插件。下载准备不占用提交队列，每个任务真正提交时重新读取设置。

插件和独立技能详情共用 ResourceRemoveDialog 模态确认，显示对象名称及后果，提供取消／确定、焦点约束与仅关闭最上层的 Escape；服务端重新按精确发现路径校验，只允许已知技能根的直属 Markdown 或直属技能目录，拒绝包提供的资源和任意外部路径。删除不将插件资源目录当作独立技能目录递归移除；无法独立删除时提示通过所属插件／来源目录管理。移除入口位于已安装列表每行右侧，和详情按钮同级，不触发详情切换；详情不再重复提供移除按钮。确认失败保留弹窗及错误；成功后清除内容缓存、刷新已安装列表与计数，仅移除当前选中资源时返回目录。共享技能文件的影响在确认文字中说明。

资源页的保存位置、技能文件、插件安装位置和工作目录统一使用 ResourcePath。路径按容器宽度省略中间，保留前部与末尾目录；项目资源路径优先保留项目目录及 .pi/skills 等末尾，不能二次裁掉末尾。悬停、键盘聚焦或触屏点击展示可选中、复制的完整路径；浮层通过 portal 定位并限制在视口内，不撑高工具栏或截断在滚动容器中。Escape 关闭浮层并阻止触发整个页面关闭，离开或点击外部收起。读取和权限校验始终使用原路径，缩略值不回传 API；其他设置页面的路径组件保持原有规则。

## 统一操作与侧栏节奏

插件与技能详情顶部返回按钮至少 78px 宽，名称旁共用 CopyButton 复制完整名称并简短反馈。插件底部统计在目录显示总计，已安装详情显示该插件各类已发现资源数量，返回恢复总计；公开目录未安装详情不捏造数量，提示安装后查看。更新和诊断保留在统计旁。

主页新会话入口使用 80px 行，内容及下方项目区域相比原布局适度下移 10px，下接 36px 项目标题，不设置列表前分隔线，也不与资源页强制对齐。插件、技能侧栏标题／筛选区域统一为 96px，搜索框高 34px，保留舒适留白，两页分隔线的位置、粗细和颜色保持一致。主页、插件和技能共用 ProjectTrustBadge，在各自头部提供同样的受限状态入口，点击打开原有信任说明；不使用内容区大横幅，也不叠加移动端提示行。窄屏保留各页可用入口。命令环境列表整行原生拖动，菜单正常点击，Alt+方向键继续排序。

默认日期工作区直接可用，不显示信任入口、不写授权记录。插件和技能目录共用“全局｜项目”分段入口。点击“项目”直接打开可搜索的具体项目选择菜单，选择后旁边展示项目名，再点“项目”可重选；点击“全局”立即返回公共安装范围，不再叠加第二个项目下拉。插件与技能分别保存自己的安装目标，切换页面互不跟随，初始均为全局。切换目标保留同一页面实例、目录搜索与滚动；已安装列表和计数保留上一份快照，新目标响应后一次替换，过时响应不得覆盖当前目标。切换期间暂停资源操作，不把暂时空数据当成未安装；下载／更新／移除进行时锁定本页目标选择，其他页保持独立。安装栏使用固定行及提示位，长名称和路径只在各自空间内缩略，信任／刷新提示不推移卡片。初始始终选择全局，不随当前会话自动切换；全局列表和安装验证不读取日期目录或当前项目的资源，旧同名副本不能遮蔽公共安装。仅主动选择具体项目后才切到项目范围；列表、路径、信任入口和安装请求一起跟随所选目标，不切换当前对话。项目选项只读取主页已登记的项目清单，按稳定身份与关联名各显示一次，不合入历史会话、最近目录或当前执行目录；清单为空时不补历史项目。零关联目录项目沿用现有目录校验入口准备私有工作区。已有未信任资源仍需明确授权，空白项目首次安装复用受检写入与失败撤销流程，不能连带信任嵌套仓库。安装、更新、删除和来源记录继续使用原有格式。服务端由 default-workspace.ts 核对应用默认根下的真实日期目录；子目录、目录链接和已登记的用户项目不能借此免授权。项目资源加载与实时配置读取使用同一判断，不能仅隐藏页面提示。

技能历史来源识别兼容旧版全局 CLI 安装：实际技能必须位于已知 CLI 全局技能根直属目录，且全局锁与应用日期工作区中的旧锁同时匹配来源、文档路径与非空版本哈希，才归入应用安装。未匹配记录仍按外置处理，不通过同名或目录中存在 SKILL.md 推断。匹配只读取旧记录，不安装、不迁移文件、不加载未信任项目资源。插件继续使用精确来源安装记录，不以目录列表中存在同名插件认定应用安装。

本轮资源页交互验证：`lib/resource-sidebar.test.mjs`、`lib/skill-documentation.test.mjs` 与 `e2e/resource-trust.mjs`（内含 `resource-sidebar-checks.mjs`，隔离验证全局继承、项目隔离、折叠、拖动、行末移除及窄屏）。

插件、技能及子代理范围选择共用紧凑的“全局｜项目⌄”控件，不展示重复的安装位置／配置范围文字，保留无障碍名称。项目菜单统一为 300px（受视口宽度限制）、至少 36px 行高和双行长名称，长列表内部滚动，手机沿用底部面板。

四处范围切换使用 `useResourceInstallTarget` 先校验目录并预读只读概览，完成后再一起提交项目名称和内容；等待期间保留原范围，立即阻止资源操作。插件、技能及子代理在绘制前恢复对应范围的概览，MCP 沿用各范围保留的页面实例。`resource-overview-cache` 仅存浏览器内存中的短期展示快照，按功能和目录隔离，最多 24 项、30 秒过期；首次预读响应由面板消费一次，返回缓存范围时后台重新读取，写操作后使对应功能缓存失效。缓存只用于展示，不作为信任授权或配置写入依据；服务端仍逐次校验。连续选择和卸载会中止旧预读，旧响应不能覆盖新目标或缓存。

加载提示统一等待 200ms 再显示，完成立即隐藏，不延迟请求或强制延长加载。提示位保持原尺寸；已有列表和范围按钮在短暂禁用时不整体变淡。首次加载前不把未知数量显示为零。浏览器回归用 `RESOURCE_SWITCH_ONLY=1 node e2e/resource-trust.mjs`，逐帧检查四页快／慢请求、缓存返回、名称与内容一致、目标独立及布局和外层滚动稳定；测试使用隔离配置与请求替身，不执行真实安装或连接。
