# 内置子智能体

## 开关与资源配置

内置实现是隐藏的内联扩展，默认关闭，配置位于 `~/.pi/agent/agents/settings.json`。普通非仅聊天会话保留工厂，即使关闭也可在重载时启用；关闭状态不注册工具，运行时守卫拒绝残留调用。

启用时，仅抑制能够明确识别为旧 `pi-subagents` 且注册保留工具的扩展；不能因为第三方碰巧同名就删除它。保留工具为 `Agent`、`get_subagent_result`、`steer_subagent`。关闭内置实现不会中止已有子任务或隐藏历史。

内置配置的关闭状态通过 `disabledBuiltIns` 名单保存，不复制系统提示词。文件覆盖仍完整替换同名内置配置，使用文件自己的 `enabled`。

## 调度、隔离与运行限制

并发上限和内置开关由设置控制；排队、前台等待、后台运行、恢复和取消保持独立状态。项目子会话继承父项目身份，创建、续接及 RPC 重开均同步最新目录清单，拥有自己的执行环境和生命周期。输入文件允许当前项目根内的绝对路径；项目命令和复制能力只随原有 Shell／读写权限开启。多目录项目的工作树隔离必须由 Agent 的 cwd 参数明确目标仓库，非隔离任务不接受该参数，也不改变全会话目录。

配置决定工具、推理级别、最大轮数和父上下文继承。`Agent` 允许模型选择类型、任务、说明、后台模式、恢复 ID、输入文件、模型和隔离方式；不能通过未公开的调用参数覆盖配置限制。

模型引用按 SDK 语义解析，先尝试完整 ID，再解析可选 `:<推理级别>`，避免误拆 `qwen3:8b` 这类 ID。恢复任务保留原配置、模型、推理级别和上下文；更改创建参数应新建子任务。

Agent 的 cwd 说明明确仅适用于工作树隔离，普通委派和续接省略；模型可见结果同时标注本次操作为新建或续接及实际会话 ID，前后台结果沿用原有首段和详情结构。不得根据任务文字或“最近一次”自动补填 resume，以免多子任务时恢复错会话。

对子代理的指代依据用户明确 ID、所分配任务及无歧义上下文定位；多个子代理均可能符合时，先询问，不按最近创建、返回次序或方便程度选择后执行。该要求通过现有工具说明和提示准则传达，不改变恢复参数、调度逻辑或权限边界。

隔离工作树清理失败时，保留现有工作树和结构化告警，并将 `worktreeCleanupError` 同时写入模型可见的完成正文；前台结果、结果收集和后台通知共用该正文，避免仅存于 details 导致模型看不到实际清理状态。

达到轮数限制时清理排队消息并拒绝继续引导，不能仅让一轮结束而被剩余队列再次启动。错误中列出未处理消息。后台任务完成通知在父任务运行时等待，并再次检查结果是否已被父任务收集，防止重复通知。

完成消费标记包含会话 ID 和本次完成时间，恢复任务沿用历史标记但区分新运行。通知以代码中的固定前缀区分于真实用户指令；恢复完成报告明确替代旧报告，避免模型逐字复述。

## 配置文件兼容

全局配置来自 `~/.pi/agent/agents/*.md`，项目配置来自 `.pi/agents/*.md` 和兼容目录。保存只改管理的 frontmatter 字段，保留外部键和 `ext:` 工具选择器。

`skills:` 列表按 SDK 发现的技能名查找，不把名称作为文件路径；预加载去掉 frontmatter 的正文并隐藏技能目录。缺失技能形成说明，其余继续加载。

`extensions:` 列表限制子任务保留的扩展及其注册模型，但扩展工厂可能已运行，因此这不是沙箱。需要扩展动态工具时，不能固定一个阻止后来注册工具的静态白名单；同时必须排除保留的子智能体调度工具，避免嵌套派发。

子任务可设置 `codemode: inherit | on | off` 和 `mcp: on | off`，缺省为关闭。启用 MCP 时使用自己的主机、项目信任和只读策略，不能共享父会话连接。

## 只读查看标签

`SubagentViewer.tsx` 使用 `agent:<sessionId>` 标签，仅读取会话详情和上下文 API，不调用 `/api/agent/`，因此查看不会启动、重开或延长智能体生命周期。

运行时轮询最新页并与已加载历史合并；有重叠则保留旧页，没有重叠则替换，旧页仅在游标仍有效时前插，避免重复或缺口。运行开始和结束重新读取元信息。子智能体标签不持久化，项目或工作区变化后清理。

## 配置页面展示

保留左右角色列表与详情布局。内置角色名称和用途按界面语言展示，ID、实际系统指令和运行配置保持原值；自定义配置不按名称套用内置说明。顶部区分内置调度总开关与角色配置开关，顶部只保留一句用途说明和启用状态，未启用时保留角色配置，状态点显示不可调用。内置详情使用只读说明、工具标签和随界面语言展示的指令译文（运行时指令保持原值），创建副本后沿用原有编辑保存流程，复制实际原始指令；用户已保存的自定义内容不自动翻译。新建角色使用本地化显示名称和输入提示，ID 保持稳定英文格式。代码模式、最大轮次、上下文继承与后台运行归入默认折叠的高级配置，折叠不清空字段或改变保存内容。

子代理配置使用独立的全局／项目选择，项目选项只来自主页已登记清单，不改变当前对话或其他资源页的目标。全局列表通过显式 scope=global 读取，仅包含内置与全局角色，无项目也可管理；选择项目后同时展示其全局及项目角色，兼容 .agents/agents 归入项目组并保留原有只读权限。分组按内置（默认折叠）、全局、项目排列并显示数量；全局范围不展示项目组，选择项目后才展示对应项目组。保存、开关、删除按已有角色的原始范围执行，新建按当前目标保存，项目操作仍校验实际目录。路径使用 InlineResourcePath 缩略并复制完整值，服务端返回实际配置目录用于新建预览，避免猜测桌面 agentDir。

切换目标保留旧列表至新响应到达，期间禁止编辑与写入；请求序号和中止信号防止旧响应覆盖。每个目标保留独立未保存草稿，已保存内容重新读取；写入及删除确认期间锁定目标。列表行末删除复用 ResourceRemoveDialog，取消不写入、失败保留弹窗、删除其他角色保留当前草稿，内置和兼容只读来源不提供删除。配置调度、权限与运行中的任务不随页面选择改变。验证入口为配置 API 与来源测试、settings-navigation 测试，以及 AGENTS_UI_ONLY=1 的 e2e/resource-trust.mjs。

模型列表使用显式 scope=global 读取全局配置，不依赖服务工作目录的访问授权，也不加载其中的项目设置或扩展；所选项目仍走 cwd 与原有权限／信任校验。
