# MCP 设置与配置写入

MCP 与子代理总开关沿用同一顶部高度和双行说明槽；保存、连接及错误反馈原位替换说明，不增加一行推移页面。工具区同时展示当前会话和手动测试提供的工具摘要，已关闭的历史连接不当作当前可用工具。

## 读取面板

`GET /api/mcp` 分别读取全局 `mcp.json` 和项目 `.pi/mcp.json`，只读取文件。打开设置不能启动服务器、联网、运行 `!command`，或为了查询状态创建认证文件和锁。

显示未经展开的配置、脱敏后的命令/URL/头字段、作用域、信任状态及最后一次连接记录。沙箱状态仅使用已完成的自检结果，不因读取面板新建工作线程。

未知字段、解析错误和无效文件单独报告；项目文件损坏不能隐藏全局文件。配置状态以 HMAC 区分内容，重启或内容改变后显示未测试，不持久保存秘密。

## 写入操作

所有修改都经过来源、JSON、工作目录、MCP 开关及权限校验，使用 SDK 配置编辑器、文件锁和原子替换。保持注释、未知字段和不相关条目，禁止把浏览器整份草稿覆盖到已变化的文件。

支持添加、启用、禁用、删除、恢复、分组切换、暴露策略、项目覆盖及登出。分组操作按条目报告成功与拒绝；被密码策略阻止的服务器保留关闭，并显示数量与原因。

作用域清楚显示写入路径。没有选中项目时只管理全局文件；项目不可信或信任范围过宽时不能写入或自动扩大信任。

## 暴露策略与项目覆盖

暴露策略决定模型每次请求携带多少工具定义：`hidden` 不声明，`codemode` 提供名称/摘要并按需搜索，`direct` 提供完整定义。旧 `codemode-deferred` 显示为 `codemode`，不再作为新选项。

全局服务器可由项目条目仅覆盖 `enabled`、`exposure`、`toolExposure`。覆盖不含 `command`、`url`、`type`，不能借它变成新的服务器。删除项目覆盖恢复全局行为，不删除全局条目。

## 删除与撤销

删除后在服务端短期保存恢复信息，浏览器只获得不透明 token。恢复窗口为 60 秒，作用域和原条目绑定；配置已发生冲突时拒绝恢复，不能覆盖新条目。过期信息和秘密及时释放。

## 信任、秘密与界面

信任对话框列出项目服务器及其真实目标，字段先转义控制字符，密钥和敏感参数遮罩。`PI_WEB_PASSWORD` 的引用标记为拒绝，不能只用隐藏值掩盖危险配置。

禁用原因、信任要求、失败信息和保存状态使用可见说明。手机不能依赖悬浮提示。焦点、Esc 和叠放对话框使用共享组件；添加草稿和选择在操作失败时保留。

顶部“启用 MCP”为全局运行开关，通过 `POST /api/mcp` 的 `set-runtime` 操作与共享设置文件锁，只更新全局 `settings.json` 中精确的 `+builtin:mcp` / `-builtin:mcp` 规则，保留其他扩展、通配规则和项目覆盖。缺省开启，保留用户明确关闭的配置；宿主级禁用不能从此开关解除。显式切换后通知已有普通会话，在空闲时应用并自动连接或断开，不用一次性连接测试替代；没有运行中会话时等进入会话后连接。打开页面和查询状态本身不启动连接。读取返回全局开关、项目覆盖和会话应用进度，应用或连接期间有限轮询，状态稳定后停止。顶部反馈始终预留原位空间，不能因保存消息新增行高。

Code mode 位于侧栏末尾的“高级设置”，选项默认折叠，保留“自动 / 始终开启”。修改全局默认工具配置，而不是在 MCP 文件中伪造服务器字段。测试与登录规则见 [测试与登录](mcp-test-sign-in.md)，导入规则见 [服务器添加](mcp-add.md)。

底部计数明确为“已配置 / 已启用”，运行关闭时另行标记，不能用配置计数暗示连接成功。侧栏分别显示尚未连接、测试通过与会话已连接，显式测试结果不等同于会话连接状态。


## MCP 范围选择

MCP 使用与资源页相同的“全局｜项目⌄”，仅列出主页登记项目，默认全局，不跟随当前会话、插件、技能或子代理的目标。全局时只读全局文件；选择项目后按全局、项目顺序列出服务器。已访问范围各自保留添加草稿、选择、测试和登录记录，隐藏面板停止刷新与登录轮询；手动启动的测试可以完成，不能把结果显示到另一个项目。切换与写入遵循原有目录、项目信任和请求校验，信任对话框明确针对所选项目。

## 范围切换与状态排版

范围工具栏位于分栏外、始终左对齐；异步通知位于右侧详情正文顶部，不能再推动工具栏、侧栏及底栏。详情滚动区预留滚动条空间、关闭滚动锚定，避免首次切换项目时通知出现、内容加载或滚动条改变造成页面跳动。各范围仍保留自己的草稿、测试和选择，取消添加例外：明确清空当次草稿。

MCP 关闭状态先展示简短状态与实际影响，完整原因、设置文件路径及诊断在“查看原因”中展开。区分宿主关闭（只读）和 builtin:mcp 关闭（仍可管理及显式测试），不自动开启 MCP。添加操作、刷新及计数共用底栏，窄屏按可用空间布局。

顶部运行开关仅保留简短用途和保存反馈。检测到会话的 MCP 被其他插件接管时，默认显示一句摘要，完整会话路径、插件位置及说明放入默认折叠的“查看详情”；不把历史会话记录误称为全部会话当前的连接情况。

高级设置直接显示脚本启用方式与内置工具调用方式，预算和运行环境收进默认折叠的“更多选项”。服务工具提供方式复用应用菜单，展示名称、说明及当前选项；工具清单单独成行。只调整展示，沿用既有配置值、保存与禁用规则。


## 显式连接控制

顶部“启用 MCP”仅控制功能，关闭断开会话的内置 MCP，保留每个服务的启用选择；再次开启恢复已启用项。新添加的全局服务器默认关闭，现有配置不迁移、不批量清空；项目服务保留导入规则。分组开关只修改自身范围，开启同步连接、关闭同步断开；部分开启同时提供“全关”。单服务开关只写本条目。配置保存后只通知已有会话，忙碌时延后应用，不创建后台会话。

详情“连接／重新连接”调用 `/api/mcp/connect`，通过既有来源、目录、信任、配置和密钥校验后，排队重新注册匹配范围、文件与配置版本的服务。再次读取配置，项目同名覆盖不会误操作全局实例。工具来自实际会话，失败保持启用选择并允许重试。没有可用会话或功能关闭时明确拒绝；未启用的服务不提供连接操作。一次性 `/api/mcp/test` 继续供添加预检、登录与兼容调用使用，不冒充会话连接。移除直接显示在详情右侧，不使用单选项菜单，沿用现有移除与撤销。
