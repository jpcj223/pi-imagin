# MCP 设置与配置写入

## 读取面板

`GET /api/mcp` 分别读取全局 `mcp.json` 和项目 `.pi/mcp.json`，只读取文件。打开设置不能启动服务器、联网、运行 `!command`，或为了查询状态创建认证文件和锁。

显示未经展开的配置、脱敏后的命令/URL/头字段、作用域、信任状态及最后一次连接记录。沙箱状态仅使用已完成的自检结果，不因读取面板新建工作线程。

未知字段、解析错误和无效文件单独报告；项目文件损坏不能隐藏全局文件。配置状态以 HMAC 区分内容，重启或内容改变后显示未测试，不持久保存秘密。

## 写入操作

所有修改都经过来源、JSON、工作目录、MCP 开关及权限校验，使用 SDK 配置编辑器、文件锁和原子替换。保持注释、未知字段和不相关条目，禁止把浏览器整份草稿覆盖到已变化的文件。

支持添加、启用、禁用、删除、恢复、分组切换、暴露策略、项目覆盖及登出。分组操作按条目报告成功与拒绝；被密码策略阻止的服务器保留关闭，并显示数量与原因。

作用域清楚显示写入路径。没有选中项目时只管理全局文件；项目不可信或信任范围过宽时不能写入或自动扩大信任。

## 暴露策略与项目覆盖

暴露策略决定模型每次请求携带多少工具定义：`hidden` 不声明，`codemode` 提供名称/摘要并按需搜索，`direct` 提供完整定义。旧 `codemode-deferred` 显示为 `codemode`，不再作为新选项。

全局服务器可由项目条目仅覆盖 `enabled`、`exposure`、`toolExposure`。覆盖不含 `command`、`url`、`type`，不能借它变成新的服务器。删除项目覆盖恢复全局行为，不删除全局条目。

## 删除与撤销

删除后在服务端短期保存恢复信息，浏览器只获得不透明 token。恢复窗口为 60 秒，作用域和原条目绑定；配置已发生冲突时拒绝恢复，不能覆盖新条目。过期信息和秘密及时释放。

## 信任、秘密与界面

信任对话框列出项目服务器及其真实目标，字段先转义控制字符，密钥和敏感参数遮罩。`PI_WEB_PASSWORD` 的引用标记为拒绝，不能只用隐藏值掩盖危险配置。

禁用原因、信任要求、失败信息和保存状态使用可见说明。手机不能依赖悬浮提示。焦点、Esc 和叠放对话框使用共享组件；添加草稿和选择在操作失败时保留。

Code mode 使用“自动 / 始终开启”选项，修改全局默认工具配置，而不是在 MCP 文件中伪造服务器字段。测试与登录规则见 [测试与登录](mcp-test-sign-in.md)，导入规则见 [服务器添加](mcp-add.md)。
