# 移动端与浏览器行为

## 桌面启动

桌面生产构建通过 `PI_IMAGIN_DESKTOP_BUILD=1` 关闭 Next 全入口预加载，避免健康检查阶段载入尚未使用的模型、终端等接口；普通网页部署保留框架默认。目录和全局设置位置查询使用 `lib/agent-dir.ts`，不能为了取得 `getAgentDir` 导入整套 SDK。

SDK 预热和外部 Pi 入口自动修复只在主进程确认 `pi-imagin:workspace-loaded` 后执行；`backend-ready` 仅表示健康检查通过，不能触发这两项任务。首屏前退出或 IPC 断开应取消等待任务。自动入口修复和用户开关写入共用队列，执行时读取最新设置，不覆盖用户刚保存的关闭状态。

启动日志仍写在应用用户目录的 `desktop.log`，包含构建 ID、桌面／后台入口、预览密钥轮换完成、Next 入口、instrumentation、HTTP 初始化、健康检查和界面阶段。不得输出预览密钥、密码、认证头、配置内容或用户对话。健康检查及后台等待日志限频；等待监测在后台就绪／退出时停止，不常驻运行，也不增加网络检查。不能仅凭 Next 的 `Ready in 0ms` 或隔离空配置测试宣称安装版已经可交互。

## 桌面标题栏

桌面窗口原生按钮与网页标题栏使用同一高度和颜色。预加载脚本仅上报标题栏实际高度及颜色；主进程校验工作区主框架来源、字段格式和范围后，按窗口缩放系数更新原生覆盖区，不能透传任意窗口参数。新增桌面模块须包含在打包文件清单中。

外观切换保留网页中心圆形扩散；中心与半径使用快照区域百分比，避免桌面缩放造成偏心和边缘覆盖不足。React 选中状态和主题变量在同一快照中更新。`data-theme-transition` 仅在快照切换期间存在，原生按钮颜色等待扩散完成再同步，避免右上角提前变色；高度仍实时测量。快速选择跳过旧动画，旧回调不能覆盖新选择或清除新标记；不支持快照及减少动态效果时直接切换，无额外等待。

窗口标题栏仍可拖动，系统最小化、最大化和关闭按钮保留。桌面搜索、项目编辑、资源移除和目录选择弹窗的遮罩从标题栏下方开始；浏览器中不设置桌面标记，沿用原有遮罩范围。

原生按钮覆盖区高度按网页实际高度乘窗口缩放系数后减去一个物理像素，为网页底部分隔线让位；标题栏高度变量仍使用完整高度，不能因此移动内容区或遮罩。验证包含 100%、125%、150% 窗口缩放。

## 工作区终端

底部终端使用顶部整条分隔线调整高度，复用 `useResizablePanel` 的垂直／向上模式。拖动、上下方向键和双击／Enter 恢复默认均可用，首选高度保存至 `pi-terminal-height`；窗口缩小时只压缩显示值，不能覆盖首选高度。默认约三分之一，普通模式为上方工作区至少保留约 420px；窗口过短时终端最小 120px，仍可使用全屏。

全屏占据右侧工作区，保留全局导航、标题栏和状态栏；仅隐藏上方对话与辅助区，不卸载聊天或终端，不更换 PTY，不清空输入和输出。还原回原高度。收起不关闭进程，显式关闭／重启继续沿用原生命周期。Escape 留给终端程序；查找框内 Escape 只关闭查找。

终端工具栏统一显示项目标签、实际 Shell、连接状态、单一下拉入口、查找、更多、全屏和收起；图标复用统一的 16px 线形 SVG。下拉按钮外不显示加号，各 Shell 使用对应图标并标出当前选择，点击新建该类型终端；列表底部独立分隔后显示“＋ 添加其他终端”，不恢复“使用首选 Shell”。添加页展示服务端检测到的已安装类型，已有类型标注已添加；额外类型加入后返回主列表，不立即启动进程。加入项保存至 pi-terminal-added-shells 并同步同页／其他窗口；损坏或不可用存储不影响默认列表。完整路径保留提示，更多提供清屏、复制终端和重启。弹层复用应用 SidebarMenu，一次只开一个；外部点击、选择、Esc、切换标签和布局变化均关闭，沿用键盘导航、焦点恢复及视口边缘适配。

初次创建沿用服务端系统环境：Windows 使用 ComSpec，其他平台使用 SHELL（缺省 /bin/sh）。手动选择保存在 pi-terminal-shell，后续新建沿用最后选择；菜单只显示实际可用的固定 Shell。Windows CMD／PowerShell 的 UTF-8 初始化由服务端固定参数完成。客户端不能指定任意可执行文件或参数。Shell 选择仅作用于新终端，与模型工具的 PowerShell 开关独立。标签刷新恢复须按终端 ID 去重，允许同目录多个 Shell；重启保留该终端实际 Shell，不被后来偏好覆盖。

Windows 额外检测 Git 标准安装目录及 PATH 中 git.exe 所在安装的 bin/bash.exe、System32／PATH 的 wsl.exe，以及 PowerShell 7 标准目录。Git Bash 使用 --login -i，WSL 使用 --cd 加工作目录，不套用 PowerShell 初始化。添加入口不下载或安装软件；安装其他终端后可手动刷新服务端检测结果。只启动固定检测类型，WSL 发行版仍由本机配置决定；未提供目录通知的 Shell 复制回退到初始目录。

“复制终端”新建相同实际 Shell、相同运行目录的独立终端，并选中新标签；不复制文字或复用原进程，也不改默认 Shell。CMD 通过 OSC 9;9、PowerShell 通过 OSC 7 提示符通知目录，支持跨数据块、中文和特殊字符；PowerShell 保留原提示符。通知路径仍须通过原有创建接口的目录访问校验。已有旧终端或未提供目录通知的其他 Shell 回退到启动目录；新建／重启 CMD 或 PowerShell 后启用跟踪。

终端使用独立的明暗 ANSI 调色板，五个应用主题分别适配背景、正文、光标与选择；正文及 16 种 ANSI 前景对默认背景的对比度至少 4.5，运行时开启 xterm minimumContrastRatio，主题和字体切换仅重绘，不创建进程。

右侧使用 xterm 6 自绘滚动条并保持可见，滑块与应用滚动条共用主题的 `--text-dim` 颜色和悬停／按下层次；14px 拖动区内以透明边框收窄为 6px 圆角滑块，轨道透明，不挤压终端正文。直接复用终端滚动缓冲区和拖动逻辑，不增加第二层滚动容器。没有超出视口的历史时滑块占满轨道，有历史时可以拖动回看；不为全屏程序或替代缓冲区虚构历史输出。

Windows 应用内的 Pi 命令入口默认传入 SDK 已支持的 `--tui-mode regular`，使 Pi 历史交给终端缓冲区，避免 ConPTY 中全屏 Pi 将滚轮退化为方向键后只切换输入历史。仅改变应用专属 terminal-bin 的启动参数，不写全局 Pi 配置、不改外部命令入口；用户显式传入 `--tui-mode fullscreen` 仍优先，其他全屏程序保持原行为。已运行的全屏 Pi 需要退出并重新执行命令，收起／展开终端不切换其模式。

同一应用内入口为 Pi 进程默认设置 SDK 支持的 `PI_HARDWARE_CURSOR=1`，避免 Windows ConPTY 在隐藏真实光标时省略位置更新，导致 xterm 输入法锚点停在行末。只影响该 Pi 进程及其子进程，不写用户环境或 Pi 设置；已有环境值和 Pi 显式光标设置仍优先。不通过扫描界面文字猜光标位置，也不改输入法事件或 SDK。

搜索默认普通文本，Aa／ab／.* 分别控制大小写、全字和正则，可以组合；100ms 更新，支持 Enter／Shift+Enter 和上下项，关闭清除装饰。扫描合并软换行，并把 UTF-16 偏移映射到实际宽字符单元格；Unicode 全字边界不依赖后行断言，不能因同一行前面的部分命中而漏掉后续全字命中。所有保留结果统一产生计数及高亮，当前项强调，最多保留 10000 项并显示 10000+；无效正则就地提示。高亮使用 xterm 公开标记和装饰 API，中文／emoji／自动换行保持定位，动态输出和尺寸变化重新计算。

搜索行在工具栏下靠右，输入与匹配选项组合宽度最多 260px、控件高 28px，导航按钮 24px；保留计数与关闭，不以浮层遮盖正文。窄屏收缩输入、按钮和间距，全部功能仍在同一行。工作区状态栏左侧保留本地工作区，右侧显示终端开关，不展示应用版本号。

终端开关／拖动／全屏与窗口变化使对话列表和输入区共同适配剩余空间。`observeChatViewport` 在尺寸变化前记录底部跟随或历史顶部位置；高度缩小时继续露出最新消息，读历史时保留位置，全屏隐藏期间不把零高度、归零滚动写成新位置。输入区和正文各自占据布局空间，不能用覆盖正文的固定定位补偿终端高度。

终端交互回归入口为 `node e2e/terminal-workspace.mjs`，使用临时会话和浏览器配置验证实际 PTY、中文粘贴、Ctrl+C、拖动／全屏、刷新及 Shell 选择；不修改用户模型和工作目录。操作系统输入法候选窗仍需在实际使用设备上检查。

## 软键盘和视口

编辑器聚焦时，视觉视口相对 `innerHeight / scale` 缩小超过 60px 才认定软键盘打开；较小变化通常是 Safari 工具栏。`hooks/useViewportHeight.ts` 将高度写入 `--app-viewport-height`，必须考虑缩放，避免输入框落到键盘后面。

WebKit 常在键盘动画结束后才稳定高度，输入法候选栏也可能不发视口事件。聚焦编辑器的输入、组合输入和按键事件应启动单条不反复重启的延迟重读链；不要每次强制滚动到顶部，否则会与浏览器的光标滚动冲突。

`html[data-keyboard-open]` 控制移动端输入工具栏、扩展状态栏、新会话项目栏及安全区间距。底部固定层使用 `--app-viewport-height`，不能仅依赖 `bottom: 0`。抽屉、右侧面板和底部菜单保持同样规则。

## 终端附加键

触屏设备在竖屏时显示两行附加键，方向来自 `screen.orientation` 或 `window.orientation`，不能根据被软键盘压缩的视口判断。按键放在终端网格末行，让 xterm 在剩余空间中重新适配。

指针按下时阻止默认行为，保持 xterm 隐藏输入框的焦点。附加键走普通终端输入路径，遵守连接状态和禁用输入检查；方向键遵守应用光标模式，CTRL/ALT 只影响下一次输入，也影响软键盘字符。

## 侧栏断点

进入移动断点时抽屉默认关闭。桌面展开偏好独立保存，只由桌面的显式开关更新；移动抽屉操作、遮罩点击不能覆盖桌面偏好。返回桌面时恢复原状态。

## 完成声音

`hooks/useAudio.ts` 使用 `pi-sound-enabled` 保存开关，并复用一个 `AudioContext`。自动播放需要用户手势解锁；输入组件负责解锁，会话完成回调负责播放。

空闲音频环境会占用输出流，平时应挂起。当前会话运行期间保持音频环境活动，结束或卸载后释放，以兼容锁屏后 `resume()` 无法及时完成的浏览器。关闭声音时立即挂起；过期或重复的声音请求不重播。

被中止的运行不属于正常完成：`agent_settled.aborted` 和 `prompt_done.aborted` 不播放声音，不显示完成通知，也不推送“任务完成”。
