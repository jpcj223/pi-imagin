# MCP 会话运行时

## 主机职责

每个会话包装器持有自己的 `McpHost`。普通设置浏览、自动命名和 Fork 不额外创建 MCP 会话；提示词准备时读取配置、检查信任并注册服务器。用户显式切换“启用 MCP”后，已有普通会话在空闲时重载资源并发起真实连接，忙碌会话等待任务结束；关闭时同样在空闲时断开。明确开启后新建的普通运行时也自动连接，不必先发送提示词。仅浏览磁盘历史仍不创建运行时。仅聊天和子代理资源边界保持独立。

普通会话保留内置 `/mcp` 工厂；内置启用时，加载过滤器只避让已知重复的 `pi-mcp-adapter` 插件，不卸载或修改插件配置，内置关闭时不避让。其他未知同名扩展仍报告冲突，不能擅自屏蔽。

`mcp` 内置工厂本身读取空服务器列表，等待时间为 0。Pi Imagin 经公共注册/注销 API 管理服务器，并通过自己的传输工厂观察连接和工具列表状态。

Pi SDK 1.2 将资源清单改为按需获取：启动等待仅跟踪工具列表，不因服务器声明资源而等待未发送的资源请求。测试通过 `hasResources` 表示提供资源，不假定连接已有资源数组，不能把没有工具的资源服务器误报为故障。

配置变化只替换发生变化的条目；状态键使用配置 JSON 的 HMAC，不能保存或暴露含凭据的原始 JSON。失败且内容未变的条目不反复自动重试，显式重新连接沿用扩展机制。

## 信任和等待

每次运行重新读取 `trust.json`，不能依赖创建会话时缓存的 `ctx.isProjectTrusted()`。配置损坏视为不信任；信任只在实际决定覆盖的目录内有效。

对需要声明的直接工具执行可中止的连接等待；后台暴露的工具可按需搜索或调用。等待发生在进入 SDK 提示词运行前，让 Stop 能取消等待并把尚未发送的输入还给编辑器。已完整等待过的服务器不会再次拖住提示词。

扩展命令不启动模型运行，应绕过不必要的连接等待；内置 `/mcp` 可注册服务器以展示状态，但不等待模型请求。

## 连接与回收

单个主机的操作串行。注销需考虑扩展尚未赋值连接的窗口，最多等待 5 秒；超时后记住已注销注册，拒绝迟到传输，避免连接脱离管理。

状态来源于实际传输。连接成功、需登录、失败、掉线和扩展名称冲突汇入进程内状态表供设置显示。失败信息包含经过脱敏的 stderr。

会话连接还观察 SDK 自身的 `tools/list`，分页完成后保存经过脱敏的工具名称、简介、只读提示和暴露方式，最多展示 500 项；不另开测试连接。重新列举替换原摘要，关闭连接后不再展示为可用工具。显式启用后必须核对内置主机确实接管，仍被其他扩展占用时报告应用失败，不能只凭配置已保存宣称开始连接。已知 `pi-mcp-adapter` 的重复命令在内置 MCP 启用时避让，其他自定义扩展不自动移除。

空闲回收由 `PI_WEB_MCP_IDLE_MS` 控制，默认 10 分钟，0 表示关闭；回收注销服务器但不会改变配置。模型的自动重试、等待输入和活动任务不能被错误视为空闲。

外部 OAuth 登录变化在下一次会话运行时检查，等待登录的服务器发现令牌变化后重新连接，不要求用户手动重载。

## 传输边界

stdio 子进程从继承环境删除网页登录密钥，并防止配置引用它；不能回退到泄漏宿主密码的默认传输。HTTP 传输使用经过验证的配置和认证，错误与状态严格脱敏。

项目覆盖只允许改变全局服务器的启用状态和暴露策略，不能伪装为第二个全局实体。第三方扩展先注册的同名服务器保留，设置面板明确报告冲突。
