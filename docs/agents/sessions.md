# 会话、分支与实时事件

侧栏通过只读 `GET /api/default-cwd` 获取默认工作区父目录，合并其直接日期子目录内的未关联会话；显式添加或重命名的目录仍作为项目。项目与默认区共用行模型、家族操作和现有 `sessionOrder`，展示分组不会改变会话原路径。

首次展示分组和自动记录项目顺序都等待默认目录元信息加载完成。已有项目浏览及刷新恢复也执行原有目录校验，文件和工作树加载、工作区切换通知在校验完成后触发；同一路径复用已登记身份，避免 Windows 大小写或分隔符差异产生别名丢失和重复项目。

## 会话生命周期

`lib/rpc-manager.ts` 为每个会话 ID 管理一个包装器，注册表和并发启动锁放在 `globalThis`，避免 Next.js 热重载重复创建。默认空闲超时为 10 分钟，`PI_WEB_IDLE_TIMEOUT_MS=0` 可关闭普通空闲回收。

关闭从 `shutdown()` 或 `destroy()` 开始即不可再接受新命令；等待扩展关闭和 SDK 释放后才移除包装器。替换只能创建一个新实例，旧实例的迟到注销不能删除新实例。扩展关闭默认最多等待 5 秒，超时仍继续释放。

Stop 遇到不理会中止信号的扩展时不能无限等待。强制空闲回收计时一旦开始，后续 Stop、状态或重载操作不能将它推迟；即使普通空闲回收关闭，也保留兜底清理。

运行或压缩过程中拒绝重载、克隆和会话替换，避免扩展持有失效环境。项目目录已删除时，浏览历史仍可用，但发送提示词必须明确拒绝，不能等到工具错误或自动重新创建原目录。

## Fork、克隆与分支

不能调用 SDK 的原地 Fork 来实现新会话，它会替换源会话 ID 和文件。跨会话分支使用独立 `SessionManager` 读取并复制选定历史，源运行和注册表保持完整。

侧栏 Fork 是磁盘操作，不启动智能体，也不改变源会话空闲计时。运行中可以复制已完成历史；正在执行 Shell、未持久化、空历史或不支持的子会话按各入口规则拒绝。复制文件保持父会话关系、模型变化、压缩、标签与自定义记录。

Fork 名称使用源显示名加四位随机后缀；再次 Fork 去掉旧后缀，避免无限叠加。没有真正名称或用户内容时使用原有无名规则，不能把占位文本保存为会话标题。

会话内分支导航与创建独立新会话是不同操作。导航恢复目标分支历史和工具负载，然后按会话资源策略重新应用固定预设。

## 删除与异步选择

删除会话及其子会话由 `lib/session-delete.ts` 统一处理，运行中的会话不删除，保留下来的子会话需要重新关联。删除同时更新置顶、归档、索引和历史缓存。

异步删除结束时，检查最新的当前选择，不能使用点击删除瞬间捕获的旧闭包；用户已切到另一个会话时不得把其输入框清空。列表刷新和工作区恢复失效始终执行。

URL 指向不存在会话时提示用户，并跳过自动恢复旧选择，避免地址中的会话与显示内容不一致。

## 实时事件与工具结果

事件通过 SSE 传输。重连恢复状态和历史，不能重复追加工具结果或完成消息。慢客户端超过队列上限时断开，优先丢弃可重建的增量，核心状态不可悄悄丢失。

显示层按 SDK 消息格式规范化工具调用，不更改扩展协议。会话文件格式、`toolCall` 与工具结果的关联、图片和完整输出路径按专用解析器处理。

`prompt_done` 是客户端发送提示词的完成信号；中止状态需要携带 `aborted`，不当作正常任务完成。停止运行不触发完成声音、浏览器通知或推送。

## 历史分页和性能

初始上下文仅取所选叶节点末尾 50 条，使用 `before` 向前分页。叶节点变化时重新建立分页边界，不能把不同分支页面拼接。历史树和上下文条目 ID 保持对应。

流式消息存入独立 `StreamingStore`，聊天列表只订阅是否运行和是否有内容；当前回复独立订阅文本，避免每个增量重渲染整个页面。普通工具事件和历史变化仍正常更新。

历史消息的 props、工具结果映射、分组视图和写入文件集合保持稳定。已完成 Markdown 块独立缓存；流式分块仅在安全的空行边界切开，不拆分代码块、数学块、前置元数据或未闭合 HTML。

代码高亮按本次任务预算延后到空闲时处理，Prism 语言按需加载，不在初始页面注册全部语言。没有代码的页面不加载高亮资源。

会话视图缓存保存时计算大小，读取不可变快照时不重复序列化；子任务状态按源记录对象缓存。工具结果图片使用稳定条目 ID 的长期缓存，只缓存成功响应。

## 侧栏状态与布局

置顶、归档、项目顺序和显示名称保存在 `pi-web-session-state.json`，使用锁、原子写入、版本和修订号。浏览器布局与折叠偏好独立保存；兼容标识保持不变。

新版侧栏隐藏置顶分组及入口，旧数据保留且仍可读取。项目统一使用 `projectOrder`，会话家族根使用可选 `sessionOrder`；通过同一状态请求、锁和原子写入保存，乐观失败回滚及跨窗口同步沿用原有实现。会话拖动只在所属项目内生效，不移动 JSONL 或改变工作目录，删除会话时清理对应顺序记录。顺序最多保存 1000 个根 ID，采用与项目顺序相同的容量限制；尚未手动排序的新会话仍按活动时间显示在前。

项目移除通过同一状态接口保存有容量限制的 `removedProjects`，仅取消展示登记，不删项目目录、会话文件或别名。普通会话在默认区保留；重新添加目录时清除该键，恢复原分组。不能只删除项目置顶记录，否则有历史或仍被选中的项目会立即重现。

列表虚拟化、拖动位置、项目分组与置顶区使用同一行模型。归档和撤销更新未读标记，异步失败不能恢复已被用户重新选择清除的状态。

桌面支持会话下方的文件区和独立文件标签，手机使用标签。文件树持续挂载，切换、折叠和重排保留展开、搜索、上传与滚动状态。关闭或禁用已聚焦控件时，将焦点交给附近仍可操作的控件，不能丢到页面根。

标题组件为 `PiImaginTitle.tsx`，显示 Pi Imagin，可点击查看版本。自动适配文字长度，不改 Logo。新会话项目栏复用侧栏选择器，切换目录时保留草稿、附件和有效模型选择。

侧栏会话链接使用当前实例 URL。普通点击原地选择，组合点击和菜单在新标签打开；浏览不会创建会话。下游集成可监听 `pi-web:session-row-contextmenu` 并同步取消默认行为；省略号始终使用内置菜单。

## 扩展界面与导出

`ctx.ui.setStatus`、组件和对话框通过现有扩展 UI 队列与请求 ID 关联。`command:/...` 状态作为按钮执行斜杠命令，不能把任意文本或 Shell 字符串当可执行状态按钮。没有可见文字时不占布局空间。

对话框取消、过期、排队和 Esc 保持请求对应关系。自定义消息默认展开，专用渲染器仍遵守 pi CLI 的显示语义。

HTML 导出调用 SDK 帮助函数，再使用迭代处理替代深层递归，避免很长历史导致浏览器栈溢出。

完整历史在右侧读取同一导出接口，使用无同源权限的沙盒文档保留 SDK 查看器，并仅追加布局、概览折叠及控件文字适配。保留导出响应的防嵌入限制；消息链接通过 SDK 的 `pi-share-base-url` 元信息指向实际导出地址，地址写入 HTML 属性时转义。切换会话或卸载时中止旧请求，避免迟到内容覆盖当前记录。

归档在侧栏原位展开，保留普通项目和默认会话；关闭归档时将失去可见控件的焦点交回归档展开按钮。

分支创建入口复用 `handleEditContent`，`replaceMessage` 必须明确返回是否恢复成功；已有草稿或待处理附件导致恢复失败时，不能设置编辑条目，否则下一次普通发送会误走分支导航。

分支树放在聊天标题下方正常占位，运行锁和叶节点切换沿用原实现。标题旁独立开关只负责显示；键盘 Enter 或空格与点击走同一选择回调。

## 外部会话发现

运行状态轮询触发轻量文件名检查，而不是递归文件监听。外部新建或删除 JSONL 文件时使会话列表失效；单纯追加消息不改变文件名集合，不能触发全量列表扫描。每次只有一个检查，并限制频率。

页面刷新时才检查磁盘是否领先于空闲包装器；运行中由当前包装器拥有写入路径，不能因外部读取重建。扫描期间基线更新则丢弃较旧比较结果，避免重复失效。

网页会话删除必须先归档：普通菜单、项目批量删除入口关闭，服务端在改写文件前验证整批归档状态。运行会话保留；恢复归档后旧删除入口应被拒绝，拒绝响应不能当作删除成功。底层删除助手的其他调用方默认行为不变。

默认区时间分组按本地自然日及家族最近活动计算，归档来源先区分默认与项目，不能使用默认日期目录名代替来源。时间分组是展示行，虚拟列表高度及拖放排序必须识别新的分组边界，不能改变 JSONL 或项目键。

归档只保留来源分组，不再套时间分组；历史时间折叠偏好保持兼容但不参与归档显示。项目占上部工作区，默认与归档在下部使用有界预留高度；展开收起只改变内部行，不能由列表行数推挤分区标题。各区复用虚拟列表滚动，不得改变虚拟行实际高度而不更新模型。完整历史的样式仅在隔离文档内适配，SDK 重绘概览后应保持折叠容器及控件中文提示，不替换事件或破坏搜索与导出。

刷新定位不能仅依赖 React 卸载。滚动时按帧更新内存锚点，pagehide 捕获阶段先记录当前定位，父工作区再保存有界的条目 ID 与偏移。不得持久化消息正文或运行状态。栏宽恢复在布局阶段完成，首帧预置尺寸必须与 panel-layout 的边界一致；独立文件工作区恢复不覆盖目录等辅助视图的显示偏好。

辅助栏显示／隐藏统一由顶部全局开关控制，窄屏遮罩不能遮挡它。完整历史的全宽阅读保留同一个沙盒文档和原 SDK 功能；只按视图宽度调整导航与正文，不新增父页面访问权限。

完整历史的全宽、恢复、刷新及列表开关使用图标，并保留中文 title 与可访问名称。全宽与刷新并入标签栏旁的独立操作区，悬停这些图标不能展开标签。历史文档宽窗口保持左右分栏结构，窄窗口导航浮层不挤动正文；宽度变化按可见记录及偏移恢复阅读位置，只在沙盒文档内保存 DOM 锚点，不持久化正文或开放同源权限。会话编号随概览折叠，SDK 搜索、筛选、跳转、隐藏记录与导出事件保持原样。
