# 文件访问、工作树与网页认证

## 项目与工作树

`lib/worktree.ts` 将 linked worktree 解析到主仓库 `projectRoot`，同仓库会话统一分组。已删除工作树的会话仍归回原项目，模型查询的回退目录也必须重新经过访问检查。

普通主仓库、指向 `.bare` 的主目录和独立 bare 仓库分别识别，不能把多个裸仓库的父目录当成共享项目根。新工作树位于 `<repoRoot>-worktrees/<安全分支名>`；已有分支复用，没有则从 HEAD 创建。删除脏工作树返回 `409 { dirty: true }`，需要显式强制操作。

只有仓库顶层显示工作树切换器，子目录显示禁用原因。文件区可切换、创建和删除；新会话栏可切换和创建。已有会话保持自己的工作目录。

文件区按项目名称切换，不逐项列出关联目录，也不提供默认目录或自定义路径入口。单目录项目平铺文件，多目录项目直接展示各文件夹的树根；搜索覆盖所有根，文件操作使用实际所属目录，跨目录引用保留绝对路径。目录配置沿用项目管理入口；界面和已有会话自动读取最新关联范围，浏览不更换会话身份或 SDK 启动目录。

模型请求中发生真正的项目范围拒绝后，执行层暂停该请求后续的项目命令和子代理委派／引导，不能立即换 Shell 继续访问。路径格式错误和允许范围内的文件缺失不触发暂停；合法文件操作仍可继续。拒绝记录通过 SDK 自定义条目保存，后台通知、自动续轮和子会话重开不能清除；子代理以父会话真实用户消息 ID 识别新请求，不把父代理自动 resume 当成用户重新确认。新的用户请求允许重新执行命令，不扩大任何关联范围。

该机制是“拒绝后的执行暂停”，不解析命令正文、不限制尚未发生拒绝的任意命令，也不撤销已经启动的进程；手动终端、第三方工具和系统进程权限仍按原机制处理，不能宣称已实现操作系统级目录隔离。

Windows 下 Git 输出的路径必须经过 `toNativePath()`，用 `samePath()` 比较，不用字符串直接相等。分支名不是文件路径，保留正斜杠。

## 文件访问边界

`/api/files` 不是任意文件系统浏览器。允许根来自会话工作目录、解析出的项目根和明确添加的目录。默认日期目录也要经 `/api/cwd/validate` 选中后才可浏览。

`lib/path-security.ts` 是统一边界：重新解析链接并规范大小写。现存路径拒绝 `..` 路径段；路由拒绝片段内编码的斜杠，避免 URL 规范化与文件系统解析顺序不同导致越权。

会话引用可以授权根之外的精确文件读取，不能授权目录列表。只认可受支持的编程和子智能体工具引用；系统消息、Code mode 脚本、上下文替换和任意第三方/MCP 结果文本不能任意扩大权限。完整输出文件和实际内置工具调用按专用解析规则处理。

UNC 路径通过专用编码保留 `//` 根，不能拆分后重新拼接成相对路径。

文件树的隐藏规则仅影响显示，不改变权限。Git 忽略检查使用一次 `check-ignore --no-index --stdin`，结合已跟踪路径保留列表项。Git 不可用、超时或不在工作树中时才使用固定排除列表。`.git` 和 `.DS_Store` 始终隐藏。

“显示忽略文件”只恢复被忽略或排除的项目，仍不显示 `.git` 和 `.DS_Store`。目录链接按真实目标授权；外部目标需要明确允许，不能仅凭仓库内的词法路径授权。批准时重新验证链接仍指向同一目标。

## 文本编辑与保存

工作区打开文本文件默认进入源码编辑，预览与 Git 差异仍从原有模式切换进入。编辑草稿按规范文件路径保存在客户端内存，切换文件、项目和主页不清空；未保存状态显示在标签中。关闭文件提供保存、放弃、取消；有未保存修改或正在保存的文件及父目录不能直接重命名或删除。

文件操作请求期间锁定当前窗口内受影响路径的编辑、保存与读取更新，包含子文件；成功后同步标签并移除旧的干净草稿，失败后解锁，迟到读取不能复活旧路径。文件 BOM 与正文开头的 U+FEFF 分别处理，读取与保存校验均保留正文字符。

Git 状态分别查询项目目录，再按仓库身份与覆盖范围合并；独立嵌套仓库保留，同仓库重叠范围不重复计数。差异在原访问校验通过后从目标文件定位仓库，已删除父目录逐级回退，不能沿用另一个仓库的会话目录。

`POST /api/file-edit` 使用既有请求来源检查与允许根，只编辑普通文件，不沿会话引用额外授权写入。`read` 返回可编辑性、原因、文本及版本；`save` 必须提交基线版本。写入通过串行队列与文件锁协调，重新核对实际路径及内容版本，同目录临时文件准备完成后原子替换；外部变化返回 409，不自动覆盖。用户比较后确认的合并保存仍核对所显示的磁盘版本。保存期间继续输入的内容保持未保存状态。

编辑限制为 1 MiB、10,000 行；支持 UTF-8、UTF-8 BOM、带 BOM 的 UTF-16 LE/BE，并保留原换行。二进制、不支持的编码、混合换行、只读、硬链接和内部配置保留查看模式，新增不完整字符或超出限制的内容拒绝保存。通用着色只用于阅读，不提供语义诊断，超过着色预算时显示纯文本。

离开页面前提示未保存内容，并尽力将本标签草稿备份到 sessionStorage，预算为 2 Mi 字符；禁用存储或超出配额时不保证刷新恢复，内存内容和离开保护仍保留。文件编辑快捷键只由编辑器处理，不占用聊天及终端的撤销、保存等按键。

## 刷新、上传和预览

文件和文件夹支持右键及省略号菜单重命名、删除。`/api/file-actions` 复用现有访问白名单，并再次检查项目内路径、真实父目录和链接；拒绝操作项目根、`.git`、`.pi` 与回收目录。

删除采用原子移动，存入当前项目的 `.pi-imagin-trash`；该目录始终从文件树隐藏。界面保存当前目录最近一次删除的撤销入口；恢复拒绝覆盖同名新文件。重命名和删除同步当前及暂存工作区的文件标签，目录操作包含已打开的子文件，不影响旁边同名前缀目录。

文件树不使用递归监听或持续轮询。运行结束、可写工具完成、窗口重新聚焦、上传完成和刷新按钮触发加载；工具完成触发最多每秒一次，保留展开状态，不显示持续转圈。

展开目录按工作目录保存于页面内 LRU，最多 20 项；切换目录恢复其集合，不提前列出尚未确认的新根。

文件区支持把系统文件拖入目录，拖到文件行时使用其所在目录；多目录项目的空白区域不接收上传。目录右键提供上传、在此目录打开终端及文件管理器入口；项目根不提供重命名和删除。顶部保留单行工具栏，终端目标跟随明确选择的目录，多目录尚未选择目标时禁用。

目录拖放、右键文件选择与聊天拖入共享 `uploadFiles()` 及上传 API。文件区先检查冲突，再选择替换或跳过；检查、冲突确认和写入固定使用同一目标目录，不能随之后的目录选择漂移。完成后展开目标路径并高亮新增文件。聊天拖入采用 `conflict=skip`，不会覆盖已有文件，上传或已存在的文件都插入引用；图片仍作为模型附件。目录不上传。

Markdown、HTML、CSV/TSV 与其他文本首次打开时默认进入源码编辑；预览与表格由用户切换，恢复标签时保留已选模式。表格解析处理 RFC 4180 引号、嵌入换行、BOM、LF/CRLF 和不规则行；TSV 使用制表符，CSV 可检测分号、制表符或竖线。行号是记录开始的文件行号，不是记录索引。分块读取时丢弃尚未完整的末条记录，后续数据到达再显示。

大表只渲染可见行，列宽抽样计算并限制范围；表头和行号固定，单元格省略时通过悬浮提示显示完整值。表格复用查看器滚动保存，不引入独立滚动状态。

## 密码节流

失败计数全局共享，不按未经信任的 IP 头分组。失败延迟从 1 秒翻倍至最多 60 秒；成功登录或空闲 5 分钟重置。状态使用 `Symbol.for("pi-web:auth-throttle")`，跨热重载及路由共享。

浏览器登录和 API Basic Auth 共用计数；有效会话 Cookie 优先验证。阻塞期间即使密码正确，Basic Auth 仍返回 429，且 Basic 成功不重置计数，避免探测接口绕过节流。
