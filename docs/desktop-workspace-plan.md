# 桌面工作区实施与验收计划

## 交付范围

复用现有智能体、模型、会话、文件访问和终端模块，落地已确认的主页工作区。完成布局阶段的检查后创建一次中文 Conventional Commit，再完成 Windows 独立桌面窗口和安装包。

## 布局阶段

- [x] 最左侧全局导航仅提供主页；返回主页保留当前会话与草稿。
- [x] 左侧提供新建会话、项目与项目内会话；底部仅保留设置。
- [x] 新建会话可直接使用默认日期目录，也支持在指定项目中创建。
- [x] 项目、会话的右键和省略号菜单保留重命名、删除、归档、置顶及其他现有操作。
- [x] 项目菜单进入文件目录；切换目录保留文件树的展开、搜索、上传与滚动状态。
- [x] 中间保留对话和输入框；顶部提供完整历史、生成标题、系统、工具与真实用量统计。
- [x] 右侧支持文件、会话目录和子代理查看；目录可定位提问、回复和标题，历史分页继续可用。
- [x] 终端位于聊天与右侧辅助区下方，默认收起；支持多个终端、重启与关闭，保持现有连接生命周期。
- [x] 设置是竖向分类的窗口内页面，包含常规、模型、技能、子代理、插件和 MCP；保留草稿、信任提示和保存逻辑。
- [x] 浅色默认外观、深海蓝强调色；保留其他主题与字体偏好，检查窄窗口及移动端。
- [x] 文件重命名、删除操作通过统一文件访问边界实现；错误与确认信息明确，不绕过路径检查。
- [x] 检查快捷键、附件、停止生成、工具预设、推理级别、分支、引用提问、导出与消息复制。
- [x] 类型检查、代码检查、相关回归测试及真实页面验证通过。
- [x] 排除凭据、开发对话、构建产物后，完成用户授权的一次布局阶段本地提交。

## 桌面阶段

- [x] 独立窗口打开工作区，自动管理本地服务，不要求用户打开浏览器或终端。
- [x] 打包运行依赖，验证 Windows 终端原生模块。
- [x] 处理重复启动、启动失败、退出及子进程回收。
- [x] 原生目录选择接入既有路径授权；外部链接通过默认应用打开。
- [x] 数据目录独立于安装目录，升级和卸载配置保留项目、会话与模型数据。
- [x] 生成 Windows 安装包、桌面快捷方式及中文使用说明。
- [x] 从实际安装目录验证启动、模型调用、文件、终端、关闭和再次启动；桌面与开始菜单快捷方式存在。

安装版验证及尚未进行的人工检查见 [桌面版说明](desktop.md)。

## 约束

布局与桌面层不改变历史会话格式、存储键、模型配置及统一权限边界。生产构建需避开同目录正在运行的开发服务。项目重命名是显示名称修改；项目移除不能隐含删除本地目录。删除会话沿用已有统一实现。
