# 主页工作区

当前布局复用原有智能体、会话、文件、终端及设置实现，不改变历史会话格式、模型配置和兼容存储键。

## 入口与区域

| 区域 | 入口与行为 |
| --- | --- |
| 全局导航 | 暂时只有主页；从设置返回当前工作区 |
| 左侧 | 新建默认工作区会话、项目与项目内会话、底部设置 |
| 项目菜单 | 重命名显示名称、项目内新会话、文件、置顶、排序、归档与明确确认的会话删除 |
| 文件树 | 左侧展开目录、搜索、上传、提及、下载；右键或省略号提供重命名和删除 |
| 中间顶部 | 完整历史、生成标题、系统提示词、工具定义、会话统计与上下文用量 |
| 对话区 | 继续保留流式消息、工具详情、分支、消息复制与引用提问 |
| 输入区 | 附件、模型、推理级别、工具预设、压缩与提示音 |
| 底部 | 可收起的多标签终端；新增、切换、重启和终止 |
| 右侧 | 文件与子代理标签，或可点击定位的提问和回复目录 |
| 设置 | 窗口内页面，包含常规、模型、技能、子代理、插件和 MCP |

项目重命名不移动磁盘目录；删除项目会话不会删除项目文件。新建默认会话无需先选择项目，项目行的加号仍可在指定项目中新建。

宽窗口同时展示左右区域。较窄窗口沿用辅助面板覆盖方式，并提供明确关闭按钮；手机使用侧栏抽屉。切换页面不终止后台会话或底部终端。

## 文件操作

重命名不覆盖同名条目，目录操作同步已打开的子文件标签。删除移入项目内 `.pi-imagin-trash`，界面可撤销该目录最近一次删除，刷新后保留入口；恢复不覆盖后来创建的同名文件。回收目录隐藏且不提交。

所有操作通过已有请求校验和允许根边界，并拒绝项目根、配置目录、目录链接及目录外路径。详见 [文件访问约定](agents/files-and-access.md)。
