# 主页工作区

当前布局复用原有智能体、会话、文件、终端及设置实现，不改变历史会话格式、模型配置和兼容存储键。

## 入口与区域

| 区域 | 入口与行为 |
| --- | --- |
| 全局导航 | 上方主页，底部设置；设置重复点击关闭并返回原工作区 |
| 左侧 | 顶部统一新建与搜索，项目与项目内会话，下方独立默认会话区域 |
| 项目菜单 | 紧凑的省略号与右键菜单，重命名、浏览项目文件、归档、查看归档与明确确认的会话删除 |
| 文件树 | 左侧展开目录、搜索、上传、提及、下载；右键或省略号提供重命名和删除 |
| 中间顶部 | 精简工具栏保留侧栏开关、会话统计与文件／目录切换；会话标题仅占聊天列 |
| 对话区 | 继续保留流式消息、工具详情、分支、消息复制与引用提问 |
| 输入区 | 多行输入卡片底部放置附件、模型、推理级别、工具预设、压缩、提示音与发送按钮；原项目／工作树选择器移到卡片下方 |
| 底部 | 横跨聊天与辅助区的多标签终端；默认收起，支持新增、切换、重启和终止 |
| 右侧 | 默认显示会话目录；功能菜单提供完整历史、系统、工具及可用的子代理入口，保留文件查看；统计由顶部用量入口打开，分支独立放在会话标题旁 |
| 设置 | 窗口内页面，包含常规、模型、技能、子代理、插件和 MCP |

项目重命名不移动磁盘目录；删除项目会话不会删除项目文件。统一新建会话默认使用当天工作区，无需先选择项目，也可通过已有项目选择器指定目录。项目行不再提供新建加号，“项目”标题旁的加号继续添加目录；移除底部“打开其他项目”。

未关联会话在下方“默认”区域显示，默认目录按服务端提供的父路径及直接日期子目录识别。显式添加或重命名的目录仍为项目；日期名称的其他目录不会误分类，历史文件保持原位。默认区支持已有家族操作和跨日期拖动排序。搜索入口位于最左侧图标栏，点击打开居中弹窗，复用原搜索接口及消息定位；手机通过侧栏头部搜索按钮打开同一弹窗。

设置、项目菜单和终端入口重复点击开关。搜索弹窗提供关闭按钮、遮罩和 Escape 关闭，保留输入法组合键处理及焦点恢复。右上角按钮只切换右侧栏显示／隐藏，保留原面板类型及内容；移除标签栏的关闭按钮和文件工具栏的重复隐藏按钮，内容切换使用右侧顶部横向标签：会话目录、文件、完整历史、系统、工具、会话信息；默认会话目录，悬停期间完整展开，点击只切换内容且允许连续选择；离开后收拢为选中的标签，内容保持不变。键盘聚焦同样可展开。触屏点击当前标签展开，标签支持鼠标／触屏拖动及 Alt+左右键排序，浏览器保存并同步偏好。顶部用量入口只打开会话信息，重复点击不隐藏右栏；会话信息与其余五个标签使用相同的切换、收拢及排序机制；顶部用量没有选中背景或强调边框。完整历史读取原 SDK 导出，在当前页隔离展示，全宽／恢复与刷新使用图标按钮，合并在标签栏旁；列表开关为搜索框前的图标。宽视图使用紧凑左右分栏；窄视图导航以浮层打开，可用遮罩、Escape 或选择记录关闭，搜索筛选始终可用。切换宽度保留同一历史视图及阅读锚点，顶部全局开关始终可用。保留历史树搜索、筛选、思考及工具输出开关、隐藏记录和 JSONL 下载；概览默认折叠，复制记录链接沿用原导出地址。导出接口的独立访问与防嵌入响应头不变。移除手动生成标题入口，服务端历史格式及命名数据不变。新建、保存、重命名等操作按钮仍执行原操作。会话删除仅在归档区提供，普通会话菜单及项目菜单不再提供删除；服务端同样拒绝未归档会话的删除请求，运行中的会话始终保留。设置关闭只隐藏并停用页面，保留未保存表单及聊天草稿。

项目和会话不再提供置顶入口或图标，项目可自由拖动排序，会话可在所属项目内拖动排序。顺序在刷新和跨窗口同步后保留；新会话先按活动时间显示在已有手动顺序前。归档和临时会话不参与拖动。旧置顶记录继续兼容，旧置顶会话在所属项目内显示。

项目省略号和右键使用同一菜单，“浏览项目文件”进入左侧文件树，点击文件在右侧查看内容，左侧“返回项目会话”恢复列表。去掉上移、下移、恢复默认名称、折叠其他项目及展开全部项目菜单项，保留项目自身展开和收起。

标题栏高 36 像素且不再显示“工作区”，全局导航宽 40 像素，侧栏默认宽 220 像素。辅助区默认占剩余宽度约 28%，限制在 260–360 像素；拖动上限同时考虑聊天空间、约 50% 的剩余宽度及 760 像素上限，旧宽度偏好也按新边界收拢。标题只在聊天列内显示，辅助区与聊天列从主工具栏下方同高开始。正文和输入框居中对齐，继续遵守用户内容宽度偏好。空白新会话输入区在聊天列居中，开始对话后及已有会话保持底部输入布局；工具预设、压缩和声音移入输入卡片底部行，操作及禁用条件不变。

新会话的原有项目／工作树选择器移到输入框下方，默认日期目录只显示“选择项目…”入口，菜单不展示默认日期路径。选中项目显示单个带“×”的名称标签；点击名称继续使用原项目菜单切换，点击“×”复用“使用默认目录”操作并携带草稿，工作树菜单保留。文件侧栏的目录选择器不变。空白页移除 Logo、名称、版本信息及随品牌区展示的更新链接；左上角品牌按钮仍可查看版本，服务端更新查询接口保留。

窗口宽度至少 880 像素时同时展示左右区域。更窄窗口沿用辅助面板覆盖方式，并提供明确关闭按钮；手机使用侧栏抽屉。设置采用左侧分类与右侧配置内容的窗口内页面。切换页面不终止后台会话或底部终端。

项目菜单新增“从侧栏移除项目”，仅通过现有状态接口保存 `removedProjects` 展示偏好，不删除目录或 JSONL。该项目普通会话归入默认区，归档会话仍可从归档或搜索访问；通过添加目录重新登记即可恢复项目，原别名和顺序保留。移除偏好遵守原有锁、原子写入、失败回滚、跨窗口同步和容量边界。

“已归档”位于默认会话区之后，原位展开／收起；普通项目和默认会话始终保留，归档列表独立滚动，继续保留恢复、菜单与会话操作。归档仅按来源分为默认和具名项目，组内直接列出会话，按归档时间排序，不显示时间分组或默认日期目录名；旧归档时间折叠偏好不再隐藏记录。普通默认会话仍按最近活动时间分为“今日”“最近3日”“以往”；最近3日为今日之前的三个本地自然日，分组不重复，午夜及窗口重新聚焦后刷新。普通时间分组、归档来源可展开／收起，复用原侧栏分组偏好保存折叠选择；计数包含折叠中的会话。每个普通时间分组保留内部手动顺序、独立分页。

项目区保留侧栏上部空间，默认区保持靠下的位置，按窗口高度预留 112–156 像素；归档存在时，在下方预留 144–210 像素。空间不足时各区按边界压缩，长列表内部滚动。普通时间分组、归档总开关和归档来源展开／收起均不改变分区边界，避免标题随行数上下跳动；无归档时不保留归档空区。空项目列表不显示通用“未找到会话”；加载、错误及项目内无会话继续由对应状态显示。会话相对所属分组缩进，时间和操作列保持对齐。完整历史的列表开关、搜索和筛选共用紧凑工具栏，不单独显示重复说明。宽窗口维持左右分栏结构，收起导航后释放宽度；窄窗口使用浮层，不挤动正文。布局切换按可见记录及偏移恢复阅读位置。历史树仅强调当前项，会话编号与概览默认收起在同一详情中，正文采用受限阅读宽度和统一主题色，保留原 SDK 搜索、筛选、跳转及导出行为。

标题仅保留“切换分支”；创建入口位于会话目录各条用户消息标题旁，消息下方的原创建入口保留。选择后沿用原有从此处编辑流程，输入区提示修改后发送才创建会话内分支，并提供取消入口；原有独立新会话与分支切换保留。已有草稿或附件时，不恢复历史消息、不进入分支编辑状态，并提示先处理草稿。

## 文件操作

重命名不覆盖同名条目，目录操作同步已打开的子文件标签。删除移入项目内 `.pi-imagin-trash`，界面可撤销该目录最近一次删除，刷新后保留入口；恢复不覆盖后来创建的同名文件。回收目录隐藏且不提交。

所有操作通过已有请求校验和允许根边界，并拒绝项目根、配置目录、目录链接及目录外路径。详见 [文件访问约定](agents/files-and-access.md)。

会话分支在聊天标题下方正常占位展开，不跨列覆盖；运行时可读但禁止切换的规则保留。生成回复时的停止、引导和后续消息组成一组，手机整组换行且停止直接可见，声音仍在原更多控件中；沿用原输入、排队和中止回调。
