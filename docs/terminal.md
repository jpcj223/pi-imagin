# 工作区终端

文件浏览器的终端按钮会在右侧标签栏打开或聚焦所选工作目录的终端。每个终端保留创建时的目录；切换标签、面板、会话或项目时，终端组件继续挂载，文件查看器则只挂载当前活动文件。

## 生命周期

- 创建前生成随机终端 ID；相同 ID 和工作目录的重复创建是幂等的，兼容 React Strict Mode。不能把已有 ID 用于另一个目录。
- `sessionStorage` 保存终端 ID、工作目录和活动布局。刷新后先查找原服务实例；进程过期或服务重启时不会悄悄新建替代进程。
- 新 PTY 的连接租期为 120 秒；订阅后取消到期计时，最后一个订阅者离开后重新计时。这也会回收未完成首次连接的终端。
- 隐藏、切换和卸载只断开客户端。明确关闭终端时，先等待创建和正在发送的输入完成，再删除 PTY；重启先终止原进程，再使用新 ID。终止失败保留标签供重试。
- Shell 退出后关闭 SSE，浏览器保留输出和退出码；无人查看的服务端记录在宽限期后过期。
- 明确终止和到期回收先向 Shell 发送 SIGHUP，两秒后仍未退出则使用 SIGKILL；服务关闭时立即终止 Shell。

## 传输和输入

输出 SSE 的 `id` 是单调递增的 UTF-16 偏移。重连使用 `Last-Event-ID`，或显式重连的 `after`，只传缺失的后缀。服务端最多保留 128 KiB 的 UTF-16 历史；游标过旧时重置终端并回放有限历史。这不是完整终端屏幕快照。慢速订阅者的响应队列满后会断开。

输入和尺寸调整按顺序执行。相邻输入合并发送，长粘贴分批处理且不拆开 Unicode 字符。输入发送失败时不自动重试，因为无法确定原输入是否已送达；重连连接原进程并创建新写入者，重启才替换进程。

## 原生依赖修复

`bin/prepare-terminal.js` 会修复 macOS 下 node-pty 的 `spawn-helper` 执行权限。当前依赖固定为 `node-pty@1.2.0-beta.15`，包含 Linux x64 和 ARM64 预编译文件。

原生模块只在创建终端时加载。缺失或不兼容时，API 返回带修复说明的 JSON 错误；空响应和非 JSON 错误显示 HTTP 状态，并提示检查服务端日志。

无法加载原生文件时，在安装目录执行：

```bash
npm rebuild node-pty --build-from-source --ignore-scripts=false --foreground-scripts
```

Debian/Ubuntu 先安装 `python3` 和 `build-essential`。该命令强制源码构建，避免继续使用缺失或不兼容的预编译文件。修复后重启 Pi Imagin。

## 验证

`npm test` 覆盖 PTY、租期、输出游标、输入队列和本地存储。`npm run test:terminal` 启动隔离的开发服务，执行桌面和移动端浏览器检查。首次运行前安装 Chromium：

```bash
npx playwright install chromium
```

浏览器检查会打印截图和日志所在的临时目录。
