## 验证限制

- Windows 未授予文件符号链接创建权限，模型配置有效链接／断链两项及原有相关链接用例跳过，未算作通过；目录链接逃逸使用 junction 实际验证。
- 原有 Windows 平台跳过的伪 Git 终止、stdio 挂起／超时夹具未强行改写；其余 MCP 连接与资源能力测试已执行。
- 浏览器使用独立数据目录、模拟历史及无效模型地址，没有调用付费模型，也不代表真实供应商连接已验证。原有多目录与权限回归通过不代表 OS 级文件隔离。
- 测试时线上技能目录请求返回 502，本轮只验证本地已安装技能及文档，不判断外部目录可用性。汇总脚本隔离该线上请求。
- 本轮没有重新执行全量生产构建、完整测试套件或原生 Windows 输入法候选框测试。
- SDK 升级后需重启实际应用后端才能完整生效。验收临时服务在结束时停止，不替换用户数据。
