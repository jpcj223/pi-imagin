# 国际化检查与修复

## 检查结论

扫描 components、hooks、app 的固定 `t(...)` 引用、直接 JSX 文案和常见界面属性，并核对英语、简体中文、繁体中文语言包。固定键引用未发现缺项；主要缺陷是部分应用文案绕过语言包而写死英文，另有项目选项帮助函数写死中文说明。

## 修复范围

- 模型设置：供应商名称提示、Base URL 说明、API 密钥字段及提示、请求头编辑、模型显示名称、默认／禁用／自定义按钮、兼容接口卡片及模型数量。
- 登录：连接账号、浏览器跳转提示、验证码说明与有效期、验证／继续／连接断开／无正文 HTTP 错误。应用状态保存翻译键和参数，显示时翻译，避免切换语言后继续显示旧语言。服务商返回消息仍保留原文。
- 文件与聊天：目录输入提示、空文件夹、文件加载、差异里的未更改行数、服务商错误前缀、压缩记录标题、查看／下载完整输出、图片不支持提示的关闭按钮无障碍名称。
- 项目选择：帮助函数改为返回 `folderCount`，界面根据当前语言显示；英语区分 `1 folder` 与多个文件夹。用户项目名不翻译。
- 三个语言包新增对应的 39 个键；复用已有默认／禁用／自定义、加载及关闭文案。API 协议名、ID、OAuth、URL 示例、命令、品牌、用户数据、模型回复和插件上游原文不翻译。

主要改动：`components/ModelsConfig.tsx`、`ChatInput.tsx`、`DirectoryPicker.tsx`、`FileExplorer.tsx`、`FileViewer.tsx`、`MessageView.tsx`、`NewSessionProjectPicker.tsx`；`lib/new-session-project.ts`；`lib/i18n/messages/{en,zh-CN,zh-TW}.ts`。注释说明本地登录状态与外部原文的边界，以及结构数据与显示文案的分工。未改认证协议、配置保存或请求参数。

## 验证

- 新增固定翻译键引用检查 1 项通过，扫描 components、hooks、app，避免界面误写不存在的键而直接显示键名。
- 新增三语言渲染 3 项通过：项目选择提示、图片提示关闭标签、服务商错误前缀及完整输出操作。项目名、服务商原文和命令输出保持原样。最后一项初次因输出默认折叠的测试前提失败，调整为显式展开后单独复测通过；未改产品折叠行为。
