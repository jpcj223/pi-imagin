# 浏览器回归测试与持续集成

测试框架基于上游 CI/E2E 方案，主要验证浏览器行为，不包含性能扫描器、逆向读取器或性能基准。

```bash
npm ci
npx playwright install chromium
npm run test:e2e
```

脚本会在可用的本机回环端口启动和停止自己的 Turbopack 开发服务。运行目录中不能已有开发服务，因为同一目录共享 `.next/dev/lock`。测试夹具在临时 `PI_CODING_AGENT_DIR` 中创建，结束后清理；不需要真实模型凭据，也不会使用现有 pi 会话。

CI 分别执行代码检查、类型检查和单元测试；另一个任务在干净目录中构建，然后设置 `E2E_SERVER_MODE=start`，使用 `next start` 执行浏览器测试。不要在正在开发的目录里构建。

## 覆盖范围

- 5,000 条消息的会话仅加载末尾 50 条记录，详情和上下文响应有大小限制，页面没有浏览器错误。
- 桌面和移动端连续加载两页较早消息，记录 ID 正确、不缺失、不重复；小会话可以一直翻页到根节点。
- 分支上下文只包含所选叶节点的历史；Markdown、代码块、真实工具调用与工具结果正常渲染。
- 聊天宽度、字号、字体及字重即时应用、刷新后恢复、跨标签同步，并可分别重置；已有草稿随设置调整尺寸。
- 桌面文件区默认位于会话下方，可通过通用设置切换回“会话 / 文件”标签，文件树和搜索状态不会因切换丢失。
- 拒绝不存在的会话和夹具项目之外的路径。
- 普通点击与 Enter 在当前页面选择会话；Ctrl 点击、中键和“在新标签打开”保留原标签的选择。置顶、归档、刷新和键盘 Fork 的导航行为一致，不额外创建会话或调用模型。
- 本地测试扩展验证对话框键盘导航、Esc 取消、折叠后保留草稿、倒计时显示和服务端到期处理。

真实模型提示词、在线流式回复和实际智能体执行不在此测试套件内。

## 失败产物

失败时把截图、Playwright 跟踪和服务日志保存到 `test-results/e2e/`，CI 会上传该目录。查看跟踪文件：

```bash
npx playwright show-trace test-results/e2e/trace.zip
```
